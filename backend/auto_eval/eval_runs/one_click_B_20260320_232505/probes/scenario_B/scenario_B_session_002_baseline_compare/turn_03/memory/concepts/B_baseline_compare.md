# B_baseline_compare
## 一句话总括
2023 EST 给出的是 **Co3O4 活化亚氯酸盐的基线框架**：chlorite 先参与 O 原子转移并形成高价 Co 物种，再衔接 ClO2 生成；2024 PNAS 则把这一框架进一步前移到 **缺陷位点层面**，强调氧空位诱导的低配位 Co 如何促进 chlorite 定向吸附/氧原子捕获并放大 ≡Co(IV)=O 生成。
## 共同机制
1. **都不是单一自由基叙事。** 两篇都指向：体系中至少涉及高价 Co–oxo/Co(IV) 物种与 ClO2，而不是“只靠一种 ROS”。
2. **都包含“chlorite → 高价 Co 物种 → ClO2”这一串联关系。**
   - 对 EST，可直接表述为：OAT 形成 Co(IV)，随后 Co(IV) 介导 ClO2 生成。
   - 对 PNAS，可直接表述为：chlorite 在低配位 Co 位点发生 O–Cl 裂解并把 O 转给 Co，形成 ≡Co(IV)=O，随后继续导向 ClO2 生成。
3. **两篇都支持双物种共同贡献有机物氧化。** 因而组会中更稳的说法是“Co 高价物种 + ClO2 协同”，而非“单一主导物种”。
4. **都说明该体系与常规 PMS/Fenton-like 体系有可比处，但不能简单按自由基/非自由基二分法处理。**
## 关键差异
### 1) 机理主轴不同
- **2023 EST 主轴：** OAT、PCET、质子增强、pH 对 Co(IV)/ClO2 相对贡献的调控。
- **2024 PNAS 主轴：** oxygen vacancies（OV）→ low-coordinated Co → chlorite directional anchoring / oxygen-atom trapping → ≡Co(IV)=O 放大生成。
### 2) 控制旋钮不同
- **EST 更强调溶液化学条件，尤其是 H+ / pH。**
- **PNAS 更强调催化剂位点工程，尤其是 OV 与低配位 Co。**
### 3) 对 ClO2 生成步骤的命名强度不同
- **EST：** 已明确使用 PCET 来描述 Co(IV) 介导的 ClO2 生成。
- **PNAS：** 当前可直接锚定的表述更稳的是“≡Co(IV)=O 进一步从 ClO2− 抽取电子并形成 ClO2”；本轮证据不足以把 PNAS 该步直接等同写成“PCET 已被证明”。
### 4) “位点来源”是否被明确展开
- **EST：** 基线机制更偏反应序列与 pH 作用，并未把“低配位 Co”作为主叙事核心。
- **PNAS：** 明确把低配位 Co 作为关键位点概念，是对 EST 基线框架的重要补充而非简单重复。
## 还不能下结论的点
1. **不能直接说“PNAS 已经证明了 PCET”。** 这是目前最需要收口的边界。
2. **不能把 “low-coordinated Co 锚定 Cl” 当成精确原文。** 更稳的说法是“定向锚定/吸附 chlorite”。
3. **不能把“三 Co(IV)=O”当成论文原句或稳定结论。** 该说法目前更像用户笔记压缩，尚未在本轮已核实材料中找到可直接支撑。
4. **不能把 EST 的 pH/质子增强叙事直接外推为 PNAS 的共同中心。** PNAS 的中心更偏缺陷位点效应。
5. **不能把两篇合并后表述成‘完全同一种机制，只是写法不同’。** 更准确的是：PNAS 在保留基线反应骨架的同时，对“为什么更容易形成高价 Co 物种”给出了位点层面的缺陷工程解释。
## 论文原文 vs 笔记压缩：汇报时的表达边界
### 可较稳归为“更偏论文原文”的点
- EST：OAT 形成 Co(IV)
- EST：Co(IV) 介导 ClO2 生成，并明确写到 PCET
- EST：proton enhancement / pH 影响 Co(IV) 与 ClO2 贡献
- PNAS：OV 诱导低配位 Co
- PNAS：低配位 Co 定向作用 chlorite，并促进 ≡Co(IV)=O 形成
- PNAS：≡Co(IV)=O 与 ClO2 双物种共同参与氧化
### 需标为“更偏笔记压缩/整合表述”的点
- “两篇的 OAT 过程是相似的”
- “PNAS 也证明了 PCET”
- “anchor Cl”
- “三 Co(IV)=O 👉 ClO2”
## 组会可直接复用的一句边界话术
**亚氯酸盐体系与 PMS/Fenton-like 体系的相似处在于都涉及高价金属位与多活性物种并存，但它不能被简单照搬为 PMS 框架，因为该体系还包含 ClO2 生成分支，并对 pH/质子及 chlorite-位点作用方式高度敏感。**
