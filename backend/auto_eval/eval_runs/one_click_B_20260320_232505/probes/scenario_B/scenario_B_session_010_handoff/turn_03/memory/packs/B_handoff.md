## 仍需回原文核对
### 1. 原文措辞级问题必须回 PDF
以下问题不能只看概念卡或笔记：
- 原文是否**明确写了** PCET；
- 原文是否真的用了 **anchor Cl** 这类表述；
- 原文是否真的支持 **三 Co(IV)=O** 这类说法；
- 原文是否把某条路径写成“已证明/已证实/已排除其他路径”。
### 2. 图-论断锚定必须回 PDF 正文
以下类型必须回图、图注、正文上下文：
- 哪张图直接支撑 Co(IV)=O；
- 哪张图支撑 low-coordinated Co 是关键位点；
- 哪张图能支持 pH 改变 Cl 物种分布并影响 ClO2 生成；
- 哪张图支撑 Ce 促进了高价 Co 形成。
### 3. 机制细节、峰归属、拟合、DFT 必须回 SI
以下问题默认要求先回 SI：
- Raman / XPS / XANES / EXAFS 的峰归属与拟合参数；
- 低配位 Co、OV、Ce 调控是否有计算模型直接支持；
- 吸附构型、形成能、反应路径、过渡态、补充对照是否完备；
- 正文没有展开的补图、补表、对照样、误差与重复性信息。
### 4. review 只能支持“方法学与共识”，不能替代单篇主证
以下内容若要严谨表达，需要回 review 先定边界，再回单篇原文落点：

- scavenger / probe / EPR / 原位谱的证据等级如何排序；
- high-valent metal-oxo 在环境催化中的常见识别框架；
- 某个说法究竟是领域共识、倾向性判断，还是个别体系现象。

## 后续问答禁区
### 1. 一旦问“原文是不是明确这么说”，默认先回原文 PDF
危险问法包括：
- “原文是不是明确说了 PCET？”
- “这篇是不是已经证明了 Co(IV)=O？”
- “作者是不是直接说 low-coordinated Co 是决定性位点？”
- “是不是已经排除了自由基路径？”
默认响应原则：
- 没有 PDF 页码 / 图号 / 段落锚点时，不给肯定句；
- 只能回答“当前概念层提示相关，但原文措辞待核”。
### 2. 一旦问“哪张图/哪个峰/哪个表证明”，默认先回 PDF 或 SI
危险问法包括：
- “哪张图直接证明了 Co(IV)=O？”
- “哪个峰说明形成了 metal-oxo？”
- “哪个表支持 Ce 提升了高价 Co 形成能力？”
默认响应原则：
- 图-论断锚定先回 PDF；
- 峰归属、拟合、计算细节先回 SI；
- 不把相关性图直接说成直接证据图。
### 3. 一旦问“是否已证明 / 已证实 / 已排除”，默认先做证据等级审计
危险问法包括：
- “是不是已经证明 chlorite 走 OAT？”
- “是不是已经证实 Co(IV) 比 ClO2 更主导？”

默认响应原则：

- 若证据不够，只能说“支持一种解释”，不能写成“已证明”。
### 4. 一旦问“领域共识 / 普适规律 / 首次性”，默认先回 review
危险问法包括：
- “高价 metal-oxo 一般都偏好 OAT 吗？”
- “低配位 Co 是否普遍更利于 chlorite 活化？”
- “这是不是首次报道 chlorite 体系中的 Co(IV)=O？”
默认响应原则：
- 先用 review 定证据等级和共识边界；
- 没有系统检索时，不下“首次/普遍/一定/必然”结论。
### 5. 一旦问“能不能直接迁移到我的体系”，默认先做可迁移性审计
危险问法包括：
- “PMS / Fenton-like 体系里的规律能不能直接拿来解释 chlorite？”
- “Ce-Co lamellar membrane 的结果能不能直接类推出当前体系？”
- “d-band 文献能不能直接证明 chlorite 也是电子结构驱动？”
默认响应原则：
- 先判断这是“启发式类比”还是“当前体系直接证据”；
- 外体系文献最多支持假说或设计灵感，不能自动升级为当前体系主证。
