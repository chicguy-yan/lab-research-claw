# B / master outline
> 用途：把当前文献部分收束成一份 thesis / group-meeting 可共用的总纲。
> 目标：用“三条线”组织 Co3O4 / chlorite 主线、Ce / 电子结构迁移线、high-valent metal-oxo / selective oxidation 桥接线，并显式标注每条线更偏向 `原文证据` 还是 `概念迁移`。
## 总体一句话
当前更稳的叙事顺序是：先立住 **Co3O4 活化 chlorite 的基线机制**，再讨论 **OV / 低配位 Co 与 Ce / 电子结构调控** 如何作为上游结构变量影响高价 Co 相关步骤，最后用 **high-valent metal-oxo / selective oxidation** 提供更大的概念框架与证明方法学；其中第一条线以同体系原文证据为主，后两条线逐步提高概念迁移占比。
---
## 主线一｜Co3O4 活化 chlorite 的基线机制
**定位：主干线 / 先讲清楚“体系里到底发生了什么”**  
**证据倾向：原文证据主导**
### 核心问题
- Co3O4 活化 chlorite 时，关键氧化物种是什么。
- Co(IV)=O 与 ClO2 是先后关系、并行关系，还是主次关系。
- pH / proton enhancement 为什么会改变反应表现。
### 当前最稳的收束
- 2023 EST 线索支持：**OAT 参与高价 Co 相关步骤形成，并进一步推动 ClO2 生成**。
- 2024 PNAS / OV-Co3O4 线索支持：**低配位 Co 位点更有利于 chlorite 锚定与 O-Cl 裂解，进而形成反应性 ≡Co(IV)=O，并与 ClO2 共同参与污染物降解**。
- 因此，当前更稳的基线表达不是“只有 Co(IV)=O”或“只有 ClO2”，而是：
  - **Co(IV)=O / ClO2 双物种协同**
  - **相对贡献受 pH 影响**
  - **pH 是机制分流变量，不只是优化条件**
### thesis / group-meeting 中的功能
- thesis：作为“本体系文献基线”和后续讨论的最低共识。
- group meeting：作为前半部分的共识区，先把“能写硬的”讲清楚。
### 写作上限
- 可以写：**Co3O4 / chlorite 体系原文证据支持高价 Co 相关路径与 ClO2 共同参与。**
- 不宜直接写：**本体系只有单一高价 Co 路径主导。**
---
## 主线二｜Ce / 电子结构 / 低配位 这条迁移线
**定位：从“机制成立”过渡到“为什么某些结构更容易走这条路”**  
**证据倾向：混合型，但整体偏概念迁移**
### 建议拆成两层
#### 2A. OV / 低配位 Co：更接近原文证据
**证据倾向：原文证据较强**
- OV-Co3O4 文献支持：**氧空位会诱导低配位 Co 位点，并增强 chlorite 锚定与高价 Co 相关步骤可达性。**
- 这一层的价值在于：把 2023 EST 的“化学步骤逻辑”补成了“结构—位点起源逻辑”。
- 因而，**低配位 Co** 可以作为从基线机制走向位点解释的中间桥。
#### 2B. Ce / 稀土电子调控：更偏概念迁移
**证据倾向：概念迁移主导**
- 相关 Ce / 稀土 / 轨道耦合 / oxo-wall 先例提示：
  - Ce 更适合作为 **电子结构调节因子** 来讨论；
  - 它可能通过局域配位重构、电子再分布、长程电子调制等方式，影响高价 Co 相关步骤的可达性。
- 但当前更稳的表述上限仍是：
  - **Ce 值得被怀疑会重塑 Co 位点并影响高价 Co 相关步骤；**
  - **这在 chlorite 体系中仍是待验证假说，而不是既成事实。**
### 这一条线在总纲中的角色
- 它负责回答：**为什么某些 Co 位点更容易走向高价 Co / 选择性氧化路线。**
- 它也为后续材料设计留入口：
  - 先从 **OV / 低配位 Co** 讲起；
  - 再把 **Ce / 稀土电子调控** 作为上游设计变量引入。
### 写作上限
- 可以写：**低配位 Co 在 OV-Co3O4 / chlorite 体系中有较强原文支撑；Ce 相关调控更适合作为待验证设计假说。**
- 不宜直接写：**Ce 已在本 chlorite 体系中促进 Co(IV)=O 形成。**
---
## 主线三｜high-valent metal-oxo / selective oxidation 的桥接线
**定位：把 chlorite 故事接到更大的理论框架中**  
**证据倾向：概念迁移主导**
### 这条线主要承担什么功能
- 不负责证明 chlorite 体系里“已经发生了什么”；
- 主要负责提供：
  - **上位概念框架**
  - **证据方法学框架**
  - **为什么这个体系值得放进 broader selective oxidation field 讨论**
### 当前最稳的桥接内容
- 可迁移的是以下分析语言，而不是外体系结论本身：
  - 电子结构调控
  - 氧化剂结合 / 活化方式
  - 高价 metal-oxo 中间体形成与稳定
  - selective oxidation vs radical over-oxidation
  - pH-sensitive pathway switching
- 可直接借用的方法学重点：
  - `18O isotope labeling`
  - 原位 / 准原位谱学
  - probe + 产物定量
  - 空白与干扰排查
  - DFT / kinetic modeling
### 这一条线在 thesis / group-meeting 中的角色
- thesis：适合放在 introduction 后段、general discussion 或 outlook。
- group meeting：适合用来解释“为什么这不只是一个亚氯酸盐特例”。
### 写作上限
- 可以写：**high-valent metal-oxo 文献为 chlorite 故事提供了概念框架与证明方法学。**
- 不宜直接写：**review 或 PMS / 膜体系 / polymerization 文献已经证明了 chlorite 体系的主导机制。**
---
## 不要混写的来源边界
### 来源标签建议
- **A｜同体系原文证据**：Co3O4 / chlorite 或 OV-Co3O4 / chlorite 原始论文结果。
- **B｜review / 综述框架**：high-valent metal-oxo 共性、证明方法、上位机制语言。
- **C｜我的笔记 / 二级整理**：上传的文献笔记、压缩总结、提炼卡片。
- **D｜旁支材料 / 外体系先例**：PMS、Fenton-like、VOC、膜体系、SAC、oxo-wall、稀土轨道耦合等。
### 主线一的边界
- 这部分若写“本体系已经发生了什么”，**必须优先回到 A 类原文证据**。
- B 类 review 只能补“为什么这样讨论”“一般如何证明”，**不能替代 chlorite direct evidence**。
- C 类笔记只能作整理入口，**不能代替原始图证**。
- D 类外体系先例不能写成：**因此 Co3O4 / chlorite 中也已经如此。**
### 主线二的边界
- “OV → 低配位 Co → 更利于 chlorite 活化”可更多依赖 **A 类原文**。
- “Ce 促进高价 Co / 打破 oxo-wall / 降低 antibonding occupancy”目前更多来自 **D 类旁支材料**，应写成：
  - 外部先例
  - 设计动机
  - 讨论旁证
  - 待验证假说
- 若只是由你的多篇笔记串起来的逻辑，则仍属于 **C 类二次归纳**，不能写成本体系内已证明因果链。
### 主线三的边界
- 这条线应明确标成 **B + D 为主**。
- review 提供的是上位概念和证明方法，外体系论文提供的是机制先例；
- 这两类都**不能反向回写成 chlorite direct evidence**。
- 尤其不能把以下内容直接写成本体系事实：
  - PMS 中的 d-band 控制律
  - polymerization 路线
  - 膜限域体系的 oxo-wall 突破
  - 外体系里 Co(IV)=O 的主导性
### 一句话警戒
- **这份总纲里，第一条线主要是“同体系原文证据”；第二条线是“原文证据 + 迁移假说”；第三条线是“概念框架与方法学桥接”。最危险的错误，是把旁支体系或 review 的话，直接写成 chlorite 体系内已经成立的事实。**

- **group meeting**：每页标一个来源标签，如 `[同体系原文证据]`、`[外体系先例]`、`[review框架]`，避免导师误判为混写。
