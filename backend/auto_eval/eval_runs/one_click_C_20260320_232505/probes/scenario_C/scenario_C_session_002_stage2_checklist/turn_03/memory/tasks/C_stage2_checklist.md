# C 阶段二初始 Co3O4 / Cu-Co3O4 合成 checklist
> 适用对象：今天按《第二阶段材料合成方法汇总》做一轮初始 **Co3O4** / **Cu-Co3O4**。
>
> 本页基于两份素材整理：
> - 合成总表：`assets/uploads/f26a14af_【第二阶段】材料合成方法汇总.md`
> - 实验记录：`assets/uploads/a57679b8_【第二阶段实验记录：M-Co3O4亚氯酸盐活化选择性降解污染物】.md`
>
> 默认历史标号沿用：**1 = Co3O4**，**3 = Cu-Co3O4**。如果你今天实际不用 1/3 号釜，允许改号，但必须整条链一起改，不能只改其中一个环节。
---
## 一、按时间顺序 checklist
### Day 1｜配液、加料、搅拌、水热
#### 0. 开工前先固定标号链
- [ ] 水热釜/内胆贴号：`1 | Co3O4`、`3 | Cu-Co3O4`
- [ ] 搅拌子对应贴号：`1-stir`、`3-stir`
- [ ] 称量舟/称量纸先写号：`1-Co`、`3-Co`、`3-Cu`、`1-U`、`3-U`
- [ ] 台面左右顺序固定：左侧始终放 1，右侧始终放 3
#### 1. 加液体到底液（100 mL 水热釜内胆）
**Co3O4（1号）**
- [ ] 量取 **乙二醇 40 mL** 加入 1 号内胆
- [ ] 加入 **H2O 20 g** 到 1 号内胆
**Cu-Co3O4（3号）**
- [ ] 量取 **乙二醇 40 mL** 加入 3 号内胆
- [ ] 加入 **H2O 20 g** 到 3 号内胆
#### 2. 加 Co 前驱体
**Co3O4（1号）**
- [ ] 称取 **Co(NO3)2·6H2O 1.455 g（5 mmol）**
- [ ] 加入 1 号内胆
**Cu-Co3O4（3号）**
- [ ] 另称取 **Co(NO3)2·6H2O 1.455 g（5 mmol）**
- [ ] 加入 3 号内胆
#### 3. 只给 Cu-Co3O4 加铜盐
**Cu-Co3O4（3号）**
- [ ] 对准 3 号标号后，称取 **Cu(NO3)2·xH2O 94 mg（0.5 mmol）**
- [ ] 将 Cu 盐只加入 **3 号内胆**
**Co3O4（1号）**
- [ ] 这一步**不加 Cu 盐**
> 关键提醒：这是今天最容易搞错样品身份的一步。加 Cu 前先口头确认一遍：
> **1 号 = 纯 Co3O4，不加 Cu；3 号 = Cu-Co3O4，才加 94 mg Cu 盐。**
#### 4. 第一段搅拌
- [ ] 稍微倾斜内胆，贴壁放入对应搅拌子
- [ ] **600 rpm 搅拌 10 min**
#### 5. 加尿素并继续搅拌
**Co3O4（1号）**
- [ ] 称取 **尿素 0.5 g**
- [ ] 加入 1 号内胆
**Cu-Co3O4（3号）**
- [ ] 称取 **尿素 0.5 g**
- [ ] 加入 3 号内胆
**继续搅拌**
- [ ] **600 rpm 再搅拌 20 min**
#### 6. 封釜水热
- [ ] 检查内胆号与外釜号一致
- [ ] 上釜前最后确认：1 = Co3O4；3 = Cu-Co3O4
- [ ] 水热条件：**160 ℃，24 h（1440 min）**
- [ ] 建议拍一张釜位照片或写纸面位置图
---
### Day 2｜转移、洗涤、干燥
#### 7. 先准备离心管
- [ ] 1 号样专用：`1A`、`1B`
- [ ] 3 号样专用：`3A`、`3B`
- [ ] 离心管**本体和盖子都写号**
#### 8. 取出水热产物并转移
**Co3O4（1号）**
- [ ] 1 号釜产物只转移到 `1A/1B`
**Cu-Co3O4（3号）**
- [ ] 3 号釜产物只转移到 `3A/3B`
> 建议顺序：**先完整处理 1 号，再处理 3 号**，不要两支样同时开着转移。
#### 9. 洗涤条件
**两支样都相同**
- [ ] **水洗 3–4 次，高转速 100 rpm**
- [ ] **乙醇洗 2–3 次，逐步降到 800 rpm**
- [ ] 判据：**上清液澄清**
- [ ] 经验判据：**“好离心” = 不粘在水热釜上**
> 记录里已有风险提示：之前出现过**产率低——离心时没注意上清液**。倒上清要慢，宁可留一点液体，也不要把沉淀倒掉。
#### 10. 干燥
- [ ] 洗后样品分别转入对应干燥容器：`1-dry`、`3-dry`
- [ ] **55 ℃ 普通烘箱** 干燥过夜
- [ ] 干燥完成后称重并记录
> 注意区分：这里是**55 ℃ 普通烘箱**，不要和另一条 p-Co3O4 路线的 **50 ℃ 真空干燥**混掉。
---
### Day 3｜煅烧、收样
#### 11. 装坩埚/瓷舟
- [ ] Co3O4 只装入 `1-CAL`
- [ ] Cu-Co3O4 只装入 `3-CAL`
- [ ] 坩埚**本体和盖子都写号**
- [ ] 进马弗炉前拍照或画炉内位置图
#### 12. 马弗炉程序
**两支样同程序**
- [ ] **5 ℃/min 升至 300 ℃，保温 2 h**
- [ ] 再 **20 ℃/min 升至 400 ℃，保温 2 h**
- [ ] 冷却后取出
#### 13. 收样
- [ ] 分别称重
- [ ] 分别装入最终样品管
- [ ] 建议最终标签写全名：
  - `Co3O4_init_YYYYMMDD`
  - `Cu-Co3O4_init_YYYYMMDD`
---
## 二、标号和防交叉污染
### 1. 今天必须同步写号的节点
以下节点只要发生“换容器 / 分装 / 外观趋同”，就必须把旧标号同步到新容器上：
- [ ] 水热釜**内胆本体**
- [ ] 水热釜**外釜本体**
- [ ] 称量舟/称量纸
- [ ] 离心管**本体 + 盖子**
- [ ] 干燥容器本体
- [ ] 坩埚/瓷舟**本体 + 盖子**
- [ ] 最终收样瓶
### 2. 建议采用的整条标号链
- 水热阶段：`1 | Co3O4`、`3 | Cu-Co3O4`
- 称量阶段：`1-Co`、`3-Co`、`3-Cu`、`1-U`、`3-U`
- 离心阶段：`1A`、`1B`、`3A`、`3B`
- 干燥阶段：`1-dry`、`3-dry`
- 煅烧阶段：`1-CAL`、`3-CAL`
- 最终样品：`Co3O4_init_YYYYMMDD`、`Cu-Co3O4_init_YYYYMMDD`
### 3. 最容易混号/交叉污染的高风险点
#### A. Cu 盐误加到纯 Co3O4
- 风险原因：两支样前面步骤几乎相同，只有 3 号多一个 Cu 盐步骤
- 防错动作：
  - [ ] 先完成 1 号 Co 样，再处理 3 号 Cu 样
  - [ ] Cu 盐称量舟必须写 `3-Cu`
  - [ ] 加 Cu 前先口头复述：**1 号不加 Cu，3 号才加**
- 如果漏写/误加：
  - 会直接破坏“纯 Co3O4 vs Cu-Co3O4”的对照
  - 后面即使性能不同，也无法确认差异来自 Cu 掺杂还是样品搞混
#### B. 转移/离心阶段混号
- 风险原因：浆液外观相似、又会一份分成两管，最容易发生串样
- 防错动作：
  - [ ] 先贴好 `1A/1B/3A/3B`
  - [ ] 一次只处理一支样
  - [ ] 不让 1 号和 3 号同时开盖并排转移
- 如果漏写：
  - 可能把 1 号一部分并到 3 号里，造成交叉污染
  - 也可能 A/B 管、管盖混错，导致残液交叉带入
  - 产率、颜色、后续性能都会失去可解释性
#### C. 倒上清时丢样
- 风险原因：前次记录已出现“离心时没注意上清液，产率低”
- 防错动作：
  - [ ] 倒上清时动作放慢
  - [ ] 看到沉淀松动就停
  - [ ] 宁可多洗一次，也不要一次倒空
- 如果操作太快：
  - 会导致样品回收率虚低
  - 干燥后称重偏低，后面会误判“这一批本来就产率差/合成失败”
#### D. 干燥后粉末外观趋同
- 风险原因：干燥后更难靠外观分辨是谁
- 防错动作：
  - [ ] 干燥容器写 `1-dry`、`3-dry`
  - [ ] 干燥结束立刻称重并装回对应容器
- 如果漏写：
  - 从干粉阶段开始，样品身份几乎不可追回
#### E. 坩埚/瓷舟进炉前后混号
- 风险原因：进出马弗炉时容易挪动位置、拿错盖子
- 防错动作：
  - [ ] 坩埚本体和盖子都写号
  - [ ] 放炉前记录炉内位置
- 如果漏写：
  - 烧后只剩两份黑粉，几乎不可能再靠肉眼区分
  - 最终样品标签和后续测试数据会整条错位
### 4. 三条死规矩
1. **任何时候都不要只在脑子里记号。**
2. **任何时候都不要只写盖子不写本体。**
3. **任何时候一旦换容器，就立刻把旧标号同步到新容器。**

## 四、极简版现场提醒
- [ ] **1 号不加 Cu；3 号才加 94 mg Cu 盐**
- [ ] **离心管、干燥容器、坩埚都要同步写号**
- [ ] **本体写号优先，盖子只是补充**
- [ ] **一次只处理一支样，不双线并排转移**
- [ ] **倒上清慢一点，别把沉淀倒掉**
- [ ] **干燥后、煅烧后都要称重并记录**
