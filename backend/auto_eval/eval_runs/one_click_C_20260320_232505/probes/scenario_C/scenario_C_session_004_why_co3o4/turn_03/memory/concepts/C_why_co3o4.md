# C_why_co3o4
## 为什么从Co3O4开始
- **先做基线，不先押宝最优体系**：当前把 Co3O4 作为起始 benchmark，不是预设其最终最优，而是因为现有第二阶段筛选里，它已经给出较明确的正信号，适合先建立可复现基线。
- **信息量足够，但变量数仍可控**：Co3O4 体系本身具备双位点/多价态特征，足以承接后续对位点分工、活化通道和高价态可能性的判断，不必一开始就引入第二变量。
- **适合做后续升级的参照系**：只有先把 Co3O4 的性能、重复性和基础机理信号钉住，后面无论引入 Ce 还是其他调控，才有清晰参照，能回答“为什么变好/没变好”。
## 升级条件
只有当以下信号出现时，才值得从 Co3O4 升级到 Ce-Co3O4：
1. **基线稳定**：Co3O4 的活性、动力学和批次结果已基本稳定，可作为可靠参照。
2. **机制信号出现**：已有数据开始提示需要进一步解释的机制差异，例如高价 Co、ClO2 或非单纯电子转移路径相关信号，但现阶段证据仍不够闭环。
3. **存在明确瓶颈**：单一 Co3O4 已暴露出持续性、选择性、稳定性或关键中间体调控上的不足，需要引入第二变量来检验是否能够改善。
4. **对照框架准备好**：至少能同时比较 Co3O4、Ce-Co3O4 与必要对照（如 CeO2 或空白基线），避免“只多做一个样品”却无法归因。
## 不能跳步的原因
- **先上复杂体系会降低归因能力**：如果一开始就进入 Ce-Co3O4 等复杂体系，掺杂、缺陷、相结构和合成波动会同时引入，很难判断变化究竟来自 Ce 本身，还是来自材料制备差异。
- **复杂化会先放大噪声，不一定放大结论**：现有实验记录已经提示，多金属/复杂体系可能带来抑制或批次不稳定；在基线未稳前升级，容易得到“结果变了”，但回答不了“为什么变了”。
- **跳过基线会削弱后续机制说服力**：如果没有 Co3O4 的稳定 benchmark，Ce-Co3O4 即使表现更好，也容易被质疑为偶然样品差异，而不是机制上有意义的改进。
- **任务推进应按‘先基线、再升级、再闭环’走**：先证明 Co3O4 值得继续做，再用 Ce 作为第二变量检验关键步骤是否被改善，这样 task 才是可执行、可复现、可解释的。
## 可直接复用的一句话
**先用 Co3O4 建立可复现 benchmark，不预设其最优；待基线稳定且出现需要第二变量解释的机制信号后，再升级到 Ce-Co3O4。**
