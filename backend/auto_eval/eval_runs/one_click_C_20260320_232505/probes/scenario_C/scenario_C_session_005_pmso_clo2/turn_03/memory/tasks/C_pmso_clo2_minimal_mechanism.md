# C_pmso_clo2_minimal_mechanism
## 最小闭环目标
在**同一催化剂/亚氯酸盐体系**中，通过并行取样同时获得：
1. `ClO2` 的时间分布；
2. `PMSO -> PMSO2` 的时间分布；
3. `PMSO` 加入前后 `ClO2` 生成的变化。
本 task 的最小目标不是直接“证明唯一机理”，而是先回答：
- 是否只有在 `催化剂 + chlorite` 活性体系中才出现明显 `PMSO2`；
- `PMSO2` 的生成是否与 `ClO2` 的生成窗口同向关联；
- `PMSO` 的加入是否削弱 `ClO2` 累积，提示两者共享上游氧化分支。
### 本 task 的结论上限
本 task 跑通后，**最多支持**：
- 体系中存在与 chlorite 活化相关的 `O-atom transfer (OAT)` 氧化分支；
- 该分支与 `ClO2` 生成存在时间关联或竞争关系。
**本 task 不能单独支持**：
- “已唯一证明为 Co(IV)=O”；
- “已排除全部非 Co(IV) 路径”；
- “已直接定量高价钴稳态浓度”。

## 实验步骤
## 1. 最小实验矩阵
### 固定推荐组别
| 组别 | 体系 | 用途 | 来源属性 |
|---|---|---|---|
| G3 | 催化剂 + NaClO2 | 主反应组，给出 ClO2 基线 | A |
| G4 | NaClO2 + PMSO | 检查无催化剂时 PMSO 是否被直接氧化 | B |
| G5 | 催化剂 + NaClO2 + PMSO | 关键机制组，同时看 PMSO/PMSO2 与 ClO2 | A/B |
### 如有余力，补充空白
| 组别 | 体系 | 用途 | 来源属性 |
|---|---|---|---|
| G1 | 催化剂 only | 催化剂空白 | B |
| G2 | NaClO2 only | 氧化剂空白 | B |
> 说明：G3/G4/G5 是最小闭环必需；G1/G2 是增强判读可靠性的空白。
## 2. 反应条件设置
### 固定原则
- 先在**无污染物体系**中跑该任务，避免变量过多。`[A/B]`
- `G3` 与 `G5` 除 PMSO 外，其余条件必须完全一致。`[A/B]`
- 催化剂先分散，再加入 `NaClO2`，定义 `t = 0`。`[A]`
- 每个时间点必须**同时取两份样**：一份测 `ClO2`，一份测 `PMSO/PMSO2`。`[B]`
### 可作为首轮摸底的参考条件（不是既定条件）
- `NaClO2 = 0.1 mM` `[B]`
- `催化剂 = 1.0 g/L` `[B]`
- `初始 pH = 6.5` `[B]`
- 反应体积 `50 mL` `[C]`
- 取样时间点：`0 / 5 / 10 / 20 / 30 / 60 min` `[B]`
> 以上数值仅作首轮摸底起点；若你当前主线已有既定条件，应优先服从当前主线条件。
## 3. 试剂准备
### 3.1 ClO2 显色支路
#### DPD 指示剂（100 mL 版本） `[A]`
- DPD：`0.44 g`
- 去离子水：先加约 `70 mL`
- 浓硫酸：`0.80 mL`
- `8 g/L EDTA-2Na`：`10 mL`
- 定容至 `100 mL`
- `0.45 µm` 过滤
- `4 °C` 避光保存
#### KI 溶液 `[A]`
- `0.5 M KI`
- 可按：`4.15 g KI` 定容至 `50 mL`
#### 缓冲液 `[A]`
- `pH 6.5` 磷酸盐缓冲液
#### ClO2 标准曲线 `[B]`
推荐点位：`0, 1, 2.5, 5, 7.5 mg/L`
> 这是分析标线建议，不是反应条件本身。
### 3.2 PMSO / PMSO2 支路
#### PMSO / PMSO2 标准品 `[A/B]`
- 需同时准备 `PMSO` 与 `PMSO2` 纯品；
- 先打单标，再打混标；
- 外标范围覆盖实际样品浓度范围。
#### HPLC 条件（仅作方法起点，不是既定条件） `[C]`
- 流动相：`30% ACN / 70% H2O`
- 流速：`1.0 mL/min`
- PMSO 检测波长：`233 nm`
- PMSO2 检测波长：`217 nm`
> 以上条件来自通用/跨体系方法整理，必须先用单标与混标验证后再用于 chlorite 样品。
#### PMSO 初始浓度 `[C/B]`
- `1 µM` 可作为外部参考起点；
- 若当前 HPLC 对低浓度 `PMSO2` 不稳定，允许先提高到 `5–20 µM` 做方法学摸底，再回落。
## 4. 开跑前的分析学检查
### 4.1 ClO2 支路 `[A/B]`
- 先跑标准曲线；
- 标线与样品必须使用同样显色顺序；
- `R² >= 0.995` 后再上样品。
### 4.2 PMSO/PMSO2 支路 `[C]`
- 先确认单标保留时间；
- 混标不串峰；
- 双波长均可稳定读出；
- 重复进样至少 3 次，峰面积 RSD 尽量 `< 5%`。
## 5. 正式取样与测定
### 5.1 ClO2 测定 SOP（固定执行） `[A]`
每个时间点：
1. 取 `5.00 mL` 反应液到显色管；
2. 加 `0.75 mL pH 6.5` 磷酸盐缓冲液；
3. 加 `0.25 mL DPD` 指示剂；
4. **最后**加入 `600 µL 0.5 M KI`；
5. 混匀后计时；
6. 在 `1.0 +- 0.1 min` 时，于 `515 nm` 读吸光度。
### 5.2 ClO2 测定必须遵守的规则 `[A]`
- `KI` 永远最后加；
- 标线与样品必须同一显色顺序；
- 加 KI 到读数的时间窗必须统一；
- 不得把该支路样品拿去做 HPLC。
### 5.3 PMSO/PMSO2 取样处理 `[A/B]`
每个时间点，从同一反应器**额外取 1–2 mL** 反应液：
1. 立即分离催化剂：优先 `0.22 µm` 针头过滤，备选快速离心取上清；
2. 上清转入 HPLC 样品瓶；
3. 置于 `4 °C`；
4. 尽量当日完成进样。
### 5.4 PMSO/PMSO2 分析注意事项
- **不能只看 PMSO 降低，必须同时看 PMSO2 增加。** `[A]`
- `PMSO` 与 `PMSO2` 的 HPLC 条件当前仅为方法参考，需先验证再正式用于样品。 `[C]`
- 当前不把 `DMSO 淬灭` 作为主 task 固定步骤，因为这部分是外部体系方法参考，未完成 chlorite 兼容性确认。 `[C]`

## 结果判读
## 1. 最小闭环成立的判据
若同时满足以下 3 条，则认为最小闭环成立：
1. `G3` 中 `ClO2` 随时间明显上升；
2. `G5` 中 `PMSO` 下降且 `PMSO2` 明显上升；
3. `G4` 中 `PMSO2` 很低或无明显生成。
### 这时允许的表述
- 在催化剂活化 chlorite 体系中，存在与 `OAT` 相关的氧化分支；
- `PMSO -> PMSO2` 主要发生在活性体系内；
- 该分支与 `ClO2` 生成窗口相伴随。
### 这时仍不允许的表述
- “已唯一证明 Co(IV)=O”；
- “已完全排除 ClO2/活性氯的直接氧化贡献”。
## 2. 若 `G5` 中 PMSO2 上升，同时 `G5` 的 ClO2 低于 `G3`
### 可判为
- `PMSO` 在截获与 `ClO2` 生成共享上游的氧化当量或中间体；
- `PMSO2` 与 `ClO2` 之间可能存在竞争/分流关系。
### 可写结论上限
- PMSO 作为 OAT 探针会扰动 ClO2 生成，提示二者共享上游高氧化态/氧转移分支。
## 3. 若 `G4`（无催化剂）中也出现明显 PMSO2
### 说明
- 在当前条件下，`PMSO` 可能被 `chlorite / ClO2 / 其他活性氯` 直接氧化；
- 此时 `PMSO2` 失去对“催化高价金属分支”的特异性。
### 这时只能说
- 存在非特异氧化；
- 不能把 PMSO2 直接当成高价钴证据。
## 4. 若 `G3` 中 ClO2 明显生成，但 `G5` 中几乎无 PMSO2
优先排查：
1. HPLC 对低浓度 `PMSO2` 是否能稳定量；
2. 取样后是否继续反应，导致样品处理失真；
3. `PMSO` 投加是否过低；
4. 当前条件下 `ClO2` 生成是否并不依赖显著 OAT 分支。
### 这时的结论上限
- 当前数据只能证明 `ClO2` 生成；
- 不能证明 `PMSO` 已成功捕捉对应 OAT 中间体。
## 5. 若只有 PMSO 下降、没有 PMSO2 增加
### 该结果不能用于机制结论
可能原因包括：
- 分析方法不稳；
- 有非目标副反应；
- 样品处理中发生损失；
- 基线或定量异常。
### 强制规则
- **只看 PMSO 消耗、不看 PMSO2 生成，不允许上机制结论。**
## 6. 最小质控判据
### 必须满足
- ClO2 标线 `R² >= 0.995`；
- PMSO / PMSO2 外标可稳定建立；
- 空白组无明显同保留时间假峰；
- 平行样偏差尽量 `< 10%`。
### 建议补充
- 粗略比较 `PMSO 消耗量` 与 `PMSO2 生成量`；
- 若二者严重不匹配，先排查分析法，再谈机制。
