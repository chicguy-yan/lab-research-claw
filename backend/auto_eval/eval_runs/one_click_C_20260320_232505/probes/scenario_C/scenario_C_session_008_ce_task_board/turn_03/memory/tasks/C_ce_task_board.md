# C_ce_task_board
## 任务目标
将 Ce-Co3O4 这条线在未来两周内拆成三条并行任务：
1. CeO2 / Ce-Co3O4 样品准备
2. 性能回测
3. 高价钴证据
近期最小闭环优先围绕 **Co3O4 vs 0.5Ce-Co3O4** 展开；CeO2 作为重要对照支线推进，但不是当前主线的硬前提。
---
## 必须做
### 1. 样品准备主线
- **锁定或补做 Co3O4 主批次**
  - 目的：作为性能和机理比较基线。
- **锁定或补做 0.5Ce-Co3O4 主批次**
  - 目的：第四阶段和第六阶段主图的核心比较对象。
- **建立批次编号与 QC 记录**
  - 至少记录：投料、回流/煅烧条件、产率、样品编号、异常现象。
### 2. 性能回测主线
- **按现有 benchmark 条件做快速体系自检**
  - 先确认体系、分析流程、旧条件是否还能复现。
- **正式做 Co3O4 vs 0.5Ce-Co3O4 性能回测**
  - 优先保留一个最稳的 ClO2- 浓度窗口。
- **至少拿到一组稳定重复结果**
  - 用于后续和高价钴证据对应。
### 3. 高价钴证据主线
- **先跑通 PMSO 最小 SOP**
  - 纯水体系；PMSO 初始浓度优先参考 0.5 mM；先解决取样和终止流程。
- **确认终止剂与取样策略**
  - 氯系体系优先采用 Na2S2O3 终止，防止氧化剂继续生成高价钴/ROS。
- **用统一批次样品做 Co3O4 vs 0.5Ce-Co3O4 的 PMSO 正式比较**
  - 作为高价钴最小证据链核心数据。
- **把性能差异与 PMSO 差异对应起来**
  - 形成“活性差异—高价钴差异”最小闭环。
---
## 有条件再做
- **CeO2 第一轮合成**
  - 按与 Ce-Co3O4 尽量一致的 HMT/90 °C 回流/450 °C 煅烧底盘路线推进。
- **CeO2 插入性能对照**
  - 用于回答“Ce 本体 vs Co 基体 vs Ce-Co 协同”。
- **ClO2 显色**
  - 在 PMSO 方法学跑顺后再补，避免方法学并行失控。
- **EPR**
  - 作为增强证据，依赖平台和时间窗口。
- **pH / 共存离子扩展**
  - 不属于当前两周最小闭环，除非主线进展明显快于预期。
---
## 依赖关系
### A. 主线硬依赖
- `样品盘点` → `Co3O4 / 0.5Ce-Co3O4 主批次锁定` → `批次编号与QC` → `正式性能回测 + 正式PMSO比较`
- 含义：正式性能和正式机理实验尽量共用同一批主样，避免批次漂移。
### B. 性能线依赖
- `benchmark 快速自检` → `正式性能回测` → `筛出最稳 ClO2- 条件窗口`
- 含义：先确认旧条件还活着，再扩大到正式数据采集。
### C. 高价钴证据线依赖
- `PMSO 最小 SOP` → `终止/取样策略确认` → `方法学试跑` → `正式 PMSO 比较`
- 含义：先把方法学跑顺，再用 precious fresh batch 打正式图。
### D. 性能-机理联动
- `正式性能回测得到最稳窗口` → `在该窗口下做 PMSO 正式比较`
- 含义：性能结果帮助筛选最值得重点验证的高价钴条件。
### E. CeO2 支线依赖
- `CeO2 第一轮合成` → （若成功）`CeO2 插入性能对照`
- 含义：CeO2 是补充对照支线，不应卡住 Co3O4 / 0.5Ce-Co3O4 主线推进。
---
## 失败回退路线
### 1. CeO2 第一轮合成不稳定
**触发条件**：几乎不沉、产率低、上清残留明显、煅烧后样品不可用。
**回退动作**：
- 不暂停主线。
- 将 CeO2 从主看板降为支线待修复。
- 第二轮仅增加一个变量：使用 NH3·H2O 调节到 pH 10.5–11，再沿用原回流/洗涤/煅烧程序。
**需要后移的任务**：
- CeO2 插入性能对照。
- CeO2 / Co3O4 / 0.5Ce-Co3O4 三者并列图。
- “Ce 本体是否单独贡献”的直接论证。
**不需要后移的任务**：
- Co3O4 / 0.5Ce-Co3O4 主批次准备。
- 性能回测主线。
- PMSO 高价钴最小证据链。
- 性能差异与高价钴差异对应。
### 2. CeO2 第二轮仍不稳定
**回退动作**：
- 本两周停止继续深挖 CeO2 工艺。
- 将 CeO2 工艺优化整体后移到下一个 sprint。
- 当前周期只保留 Ce-Co3O4 主线闭环：性能回测 + PMSO 证据，必要时再补显色/EPR。
### 3. PMSO 方法学不稳定
**触发条件**：标线不稳、终止不彻底、取样点混乱、重复性差。
**回退动作**：
- 暂停显色与 EPR。
- 优先把 PMSO 标线、取样时间点、Na2S2O3 终止流程跑顺。
- 性能回测继续推进，不被机理方法学完全拖住。
### 4. fresh batch 暂时不稳定或未及时拿到
**回退动作**：
- 先用旧样做方法学预实验。
- 不把旧样结果当最终主图。
- fresh batch 一旦稳定，再补正式对比图。
---
## 判断哪些任务会整体后移
如果 **CeO2 合成不稳定**，整体后移的是 **CeO2 对照支线**，而不是整张 Ce-Co3O4 主板。真正会导致整板明显后移的，是以下三类问题：
- Co3O4 / 0.5Ce-Co3O4 主批次拿不到或不可重复；
- benchmark 条件下性能回测不稳定；
- PMSO 方法学一直跑不通。
---
## 当前建议的执行顺序
1. 先锁定 Co3O4 / 0.5Ce-Co3O4 主批次。
2. 同步做 benchmark 快速自检。
3. 并行推进 PMSO 最小 SOP。
4. 在最稳性能窗口下做正式 PMSO 比较。
5. CeO2 支线并行尝试；若失败，仅后移 CeO2 对照，不拖主线。
