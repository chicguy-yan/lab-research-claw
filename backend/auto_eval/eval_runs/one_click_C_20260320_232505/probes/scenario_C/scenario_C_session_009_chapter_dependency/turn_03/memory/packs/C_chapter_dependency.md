# C_chapter_dependency

## 第一章

### 章节定位
- 主题：高价钴选择性生成。
- 当前可先写的安全重心，不宜直接写成“已被直接证明生成 Co(IV)=O”，而应先组织为：**OAT 型氧化物种与 ClO₂ 并行生成特征**。
- 第六阶段主线明确指出：本章可不涉及污染物，先在无污染物体系中建立证据链。

### 当前可先推进的实验与写作对象
1. **材料表征**
   - 作为章节开头，交代材料结构、组成与后续反应差异的基础。
2. **ClO₂ 定量**
   - 采用 DPD–KI 法，在 515 nm 定量。
   - 可先写标准线、时间曲线、不同条件下的 ClO₂ 变化。
3. **PMSO → PMSO₂ 探针结果**
   - 可作为 OAT 型氧化物种的 supporting evidence。
   - 当前适合写成“与高价钴相关路径一致”，不宜写成 direct proof。
4. **条件变化下的比较图**
   - 若已有不同样品或不同反应条件数据，可纳入本章形成趋势图与比较图。

### 当前可写到哪一层
- **事实层**
  - 体系可生成 ClO₂。
  - 体系中可观察到 PMSO 向 PMSO₂ 的转化。
- **Supporting evidence 层**
  - PMSO/PMSO₂ 结果支持存在 OAT 型氧化物种。
  - 该结果与高价钴相关路径一致。
- **必须留白层**
  - “Co(IV)=O 已被直接证明生成”
  - “高价钴被 EPR 直接捕捉”
  - “氧原子来源已被直接确认”

### 建议的小节结构
#### 1.1 材料结构与反应基础
- 材料表征。
- 结构与反应行为之间的关联框架。

#### 1.2 ClO₂ 的生成与定量特征
- DPD–KI 方法。
- 标线、时间曲线、条件比较。

#### 1.3 OAT 型氧化物种的 supporting evidence
- PMSO → PMSO₂ 转化。
- 用保守措辞讨论其与高价钴相关路径的一致性。

#### 1.4 当前证据边界与待补 direct proof
- 明确说明尚缺 H₂¹⁸O 或时间分辨 EPR 等 direct proof。
- 本章现阶段只能提出“最被支持的解释”，不能写成已完全证实。

### 本章关键卡点
- direct proof 暂时做不出来时，标题与论断必须降级。
- 若没有 H₂¹⁸O 或时间分辨 EPR，不要把 supporting evidence 写成 direct proof。
- 需要持续补材料表征与机制文献锚点，避免章节过薄。

## 第二章

### 章节定位
- 主题：苯酚选择性降解。
- 当前最适合先推进的是：**活性图 + 动力学 + 淬灭响应**。
- 第六阶段主线已给出顺序：先活性图，再参数图，最后淬灭实验。

### 当前实验依赖顺序
1. **先确定苯酚初始浓度**
   - 这是第二章所有活性图和动力学比较的前提。
2. **0.5 g/L 投加量下不同负载量活性图**
   - 先形成材料差异的第一张主图。
3. **不同催化剂投加量**
   - 用于建立剂量-性能关系。
4. **不同亚氯酸盐投加量**
   - 用于建立氧化剂窗口。
5. **最后做淬灭实验**
   - 主线文件已明确把淬灭放在后面。
   - 但目前仍有一个卡点：淬灭实验是针对苯酚去除，还是针对体系物种，需要先定义。

### 当前可先推进的写作对象
1. **活性图**
   - 不同材料、不同投加量、不同氧化剂投加量的浓度-时间曲线。
2. **动力学拟合**
   - 依据 GraphPad 笔记，先做 Y 轴公式转换，再做线性拟合。
   - 可统一输出 kobs 或斜率比较图。
3. **淬灭实验结果**
   - 可先写“不同淬灭剂对苯酚去除的影响”，但结论层级需保守。

### 当前可写到哪一层
- **事实层**
  - 苯酚去除活性差异。
  - 不同投加量条件下的动力学差异。
  - 淬灭剂加入前后去除率或速率变化。
- **Supporting evidence 层**
  - 淬灭结果支持某些氧化路径参与苯酚去除。
  - 活性差异与第一章提出的高价钴相关 OAT 路径一致。
- **必须留白层**
  - “苯酚主要由 Co(IV)=O 主导降解”
  - “淬灭实验直接证明 Co(IV)=O 是唯一主导物种”
  - “ClO₂ 对苯酚贡献可忽略”

### 建议的小节结构
#### 2.1 苯酚去除活性图
- 不同负载量。
- 不同催化剂投加量。
- 不同亚氯酸盐投加量。

#### 2.2 动力学拟合与多维比较
- 原始数据图。
- 伪一级动力学拟合。
- kobs 或斜率对比。

#### 2.3 淬灭响应及其保守解释
- 不同淬灭剂引起的速率或终点差异。
- 用“参与可能性”而不是“唯一归因”来讨论。

#### 2.4 与第一章机制背景的挂钩
- 写成“与第一章中 OAT 型氧化物种 supporting evidence 一致”。
- 明确不能把第一章未完成的 direct proof 直接挪来写死第二章。

### 本章关键卡点
- 苯酚初始浓度未定。
- 淬灭实验对象与解释框架未定。
- 若第一章 direct proof 缺失，第二章机制讨论必须控制结论上限。

## 共用方法与卡点

### 两章共用的方法底座
1. **同一批材料与编号管理**
   - 第一章的表征与第二章的活性图最好尽量绑定同一批样品。
2. **统一反应体系框架**
   - 催化剂 + 亚氯酸盐 + 时间点采样。
3. **统一检测平台**
   - HPLC：苯酚、PMSO、PMSO₂ 等。
   - UV-vis：ClO₂ 的 DPD–KI 定量。
4. **统一数据处理模板**
   - 按 GraphPad 笔记：
     - 原始数据录入
     - Y 轴公式转换
     - 线性拟合
     - 图尺寸和配色统一
5. **统一图形输出逻辑**
   - 原始时间曲线
   - 线性拟合图
   - 参数比较图或条形图

### 两章共用的关键对照思路
- 无催化剂对照。
- 无亚氯酸盐对照。
- 样品自身空白。
- 标线/校准同批进行。
- 若进入 direct proof：
  - H₂¹⁶O / H₂¹⁸O 对照
  - H₂O / D₂O 对照

### 章节之间的依赖关系
- 第一章给第二章提供：
  - OAT 型氧化物种与 ClO₂ 的边界信息。
  - 机制讨论的上限与保守表述框架。
- 第二章反向给第一章提供：
  - 哪个样品、哪个投加窗口最值得优先补 direct proof。
  - 哪类条件下现象最强，值得回到第一章做深证据。

### 现在最影响推进的共用卡点
1. **direct proof 缺失**
   - 没有 H₂¹⁸O 或时间分辨 EPR 时，第一章必须降级表述，第二章不能写满机制。
2. **苯酚初始浓度未锁定**
   - 会影响第二章全套活性图的可比性。
3. **淬灭实验的对象未定义**
   - 需要先明确“针对苯酚去除”还是“针对体系物种变化”。
4. **GraphPad 模板还未固定**
   - 若不同图用不同公式、不同配色、不同尺寸，后续写作会返工。

### 当前最稳的并行推进策略
- **A 线：第二章先出活性图与动力学图**
  - 苯酚浓度、不同负载量、不同投加量、不同亚氯酸盐投加量。
- **B 线：第一章同步搭最小证据链**
  - DPD–KI 测 ClO₂。
  - PMSO → PMSO₂。
- **C 线：后续择优补 direct proof**
  - 先根据第二章筛出最优样品，再做 H₂¹⁸O 或时间分辨 EPR。

### 可直接复用的安全表述原则
- 可写：
  - “supports”
  - “is consistent with”
  - “suggests the involvement of”
- 不可提前写死：
  - “directly proves”
  - “confirms the exclusive role of”
  - “dominates the degradation pathway”
