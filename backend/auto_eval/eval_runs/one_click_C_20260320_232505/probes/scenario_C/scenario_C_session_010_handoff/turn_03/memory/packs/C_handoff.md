# C_handoff
> 用途：给后续自己/同门/助手快速接班。
> 目标：把第二阶段合成、第四阶段 Ce 主线、第五阶段最小机理闭环、第六阶段高价钴主线，收束成一张可执行 handoff。
> 结论边界：本文件是任务与证据缺口整理，不把未完成的方法学或未闭环的机理写成既成事实。
## 当前任务板
| 主线 | 当前在飞的任务 | 当前最缺什么 | 下一步先做什么 |
|---|---|---|---|
| 第二阶段：材料合成底盘 | 1) 锁定 Co3O4 主批次；2) 锁定 0.5Ce-Co3O4 主批次；3) 统一样品编号、批次记录、产率和异常备注；4) 维持洗涤-干燥-煅烧流程稳定 | 最缺的是**稳定主批次 + 完整批次记录**；当前最大风险不是“不会合成”，而是标号链断、离心倒上清丢样、不同批次混用 | **先补 fresh batch 的 Co3O4 和 0.5Ce-Co3O4**，把投料、洗涤次数、干燥方式、煅烧程序、最终称重全部记全；CeO2/Cu/形貌支线先不抢主线资源 |
| 第四阶段：Ce-Co3O4 主线 | 1) Co3O4 vs 0.5Ce-Co3O4 性能回测；2) 找最稳的 ClO2- 条件窗口；3) 把性能差异和后续机理差异挂上钩；4) CeO2 作为支线对照待命 | 最缺的是**同一批样品、同一窗口下可重复的主对比数据**；不是先缺 CeO2，也不是先缺大而全机理 | **先做 benchmark 快速自检 + 正式性能回测**，尽快锁定一个最稳的 ClO2- 条件窗口；CeO2 支线不应卡住主板 |
| 第五阶段：最小机理闭环 | 1) DPD-KI 做 ClO2 定量；2) PMSO/PMSO2 做 OAT 证据；3) 跑 G3/G4/G5 最小矩阵；4) 同时间点双支路取样；5) 验证终止/过滤/HPLC 条件 | 最缺的是**方法学可用性**：DPD 标线是否稳、PMSO/PMSO2 单标/混标是否稳、Na2S2O3 终止是否真停反应、双支路取样是否同步 | **先跑方法学，不先铺 EPR**：先把 DPD 标线、PMSO/PMSO2 保留时间与重复性、终止/过滤流程跑顺；然后再上 G3/G4/G5 正式矩阵 |
| 第六阶段：高价钴主线 | 1) 用 PMSO 形成高价钴/OAT 的正式比较；2) 让性能差异和 PMSO 读出一对应；3) 必要时补直接 EPR/本征谱；4) 为第一章准备能成图的数据 | 最缺的是**章节级最小证据链**：同一批样品、同一条件下的“活性差异—ClO2/OAT 差异—可补的谱学锚点”三件套 | **先在最稳窗口下做 Co3O4 vs 0.5Ce-Co3O4 的正式 PMSO 比较，并同步测 ClO2**；趋势清楚后再决定是否补直接 EPR，DMPO/TEMP 型 EPR 暂后置 |
### 当前推荐执行顺序
1. 先锁定 **Co3O4 / 0.5Ce-Co3O4 主批次**。
2. 先做 **benchmark 快速自检** 与 **正式性能回测**。
3. 并行做 **DPD-KI + PMSO/PMSO2 方法学**。
4. 在最稳窗口下跑 **G3/G4/G5 最小闭环**。
5. 再把结果升级成 **第一章级别的正式证据链**。
### 当前不建议优先展开
- CeO2 支线先扩成主线
- DMPO/TEMP 型 EPR 先全面铺开
- 大而全的淬灭矩阵先做满
- 苯酚第二章先抢在第一章前面
- 多条新对比样路线同时并行扩张

## 未闭环的关键证据
| 证据层 | 当前还没闭环的点 | 为什么它是关键缺口 | 达到“可往下写/往下答”的最低判据 |
|---|---|---|---|
| 样品层 | Co3O4 与 0.5Ce-Co3O4 是否来自**稳定且可追踪的主批次** | 若批次混用，后面性能差异与机理差异都无法对应 | 两支主样有完整批次编号、投料、洗涤、干燥、煅烧、称重与异常记录 |
| 性能层 | Co3O4 vs 0.5Ce-Co3O4 是否已有**同条件、可重复**的正式对比 | 没有主板性能差异，后面机理比较缺落脚点 | 在同一窗口下至少拿到一组稳定重复的正式性能数据 |
| ClO2 支路 | DPD-KI 标线、显色顺序、读数时间窗是否已经稳定 | ClO2 数据不稳时，无法与 PMSO/OAT 结果联动 | 标线可用；样品与标线显色顺序一致；KI 最后加；读数时间窗统一 |
| PMSO 支路 | PMSO/PMSO2 单标、混标、保留时间、重复性是否稳定 | 只看到“PMSO 降低”不能构成机制证据，必须同时看到 PMSO2 | 单标/混标可分辨；峰形和重复性可接受；样品中能稳定读到 PMSO 与 PMSO2 |
| 取样终止层 | 终止/过滤/取样后是否还在继续反应 | 若取样后继续反应，时间点数据失真 | 明确并验证终止剂、过滤流程、进样前保存条件 |
| 最小机理闭环层 | G3/G4/G5 是否已经跑完并可解释 | 这是当前最小闭环的核心，不跑完就很难说到 OAT 分支 | G3 有 ClO2 基线；G5 有 PMSO→PMSO2；G4 低背景；并且能做时间关联判断 |
| 高价钴主线层 | 是否已把“活性差异—PMSO 差异—ClO2 变化”放在同一批样品、同一窗口下比较 | 没有这一层，就只能说“有线索”，还不能形成章节级证据链 | 同一批 Co3O4 / 0.5Ce-Co3O4 在同条件下完成性能 + PMSO + ClO2 联动对比 |
| 谱学补强层 | 是否需要直接 EPR，本征信号能否拿到 | 这不是第一优先，但会影响第一章证据强度 | 先完成显色/探针最小闭环；若趋势清楚，再决定是否上直接 EPR |
### 目前最稳的结论上限
当前最稳只能推进到：
- 先建立 **ClO2 定量 + PMSO/PMSO2 OAT 功能证据** 的最小闭环；
- 再把它和 **Co3O4 vs 0.5Ce-Co3O4** 的性能差异对应起来；
- 暂时**不能**仅凭单条 PMSO 或单条 EPR 结果，写成“已唯一证明 Co(IV)=O”。
### 当前最危险的过度表述
- “已经唯一证明为 Co(IV)=O”
- “已经完全排除全部非 Co(IV) 路径”
- “只看 PMSO 降低就能说明高价钴成立”
- “EPR 没看到就说明目标物种不存在”

## 后续问答禁区
> 以后若继续问实验设计，以下类型的问题**不应直接补一个顺手条件**；应先提醒回 **SOP / 原始记录 / 方法文档**。
### 1. 必须先回 SOP / 原始记录 / 方法文档的问题类型
| 问题类型 | 先回什么 | 为什么不能直接编条件 |
|---|---|---|
| 合成配方：投料量、溶剂体积、加料顺序、陈化时间、煅烧程序 | 合成 SOP + 当批原始记录 + 样品编号台账 | 这类参数对样品结构和批次一致性最敏感，不能用“常见值”代替 |
| 洗涤/离心/干燥细节：洗几次、转速、是否倒上清、是否真空干燥 | 原始记录 + 成功批次操作卡 | 这是当前主线已暴露出的高风险点，直接补条件很容易把批次做废 |
| 终止/淬灭/过滤/取样流程 | 方法文档 + 原始记录 | 是否真正“停反应”直接决定时间点与机理结果是否可信 |
| HPLC/DPD-KI/PMSO 条件：流动相、波长、保留时间、加样量、显色时序 | 方法文档 + 标线 + 原始峰图/显色记录 | 分析方法没锁定前，直接报数值会把方法学问题误当机理结论 |
| EPR 参数：捕获剂浓度、功率、扫描范围、时间常数、取样节奏 | EPR SOP + 仪器方法文件 + 空白/对照谱 | 强仪器依赖，不能拿别体系参数直接平移 |
| 淬灭剂浓度：TBA、FFA、BQ、L-His、Na2S2O3、PMSO 等加多少 | 淬灭实验 SOP + 干扰/空白记录 | 高浓度时试剂会从“判别”变成“重构体系”，不能只凭套路报数 |
| 仪器专属设置：pH 计、离心机、马弗炉、HPLC、EPR | 仪器本地 SOP / 现有模板方法 | 同名参数在不同仪器上可能并不等价 |
| 样品编号/批次映射：哪批样对应哪组数据 | 批次台账 + 原始实验记录 | 这决定性能与机理能否一对应，不能靠记忆补全 |
### 2. 只可先给“设计框架”，不能先给死数的问题
- “帮我设计一个最小实验矩阵”
- “哪个对照最值得先做”
- “这个阶段先做性能还是先做机理”
- “这个体系能不能借另一个体系的方法”
- “需不需要先做 EPR/淬灭/探针”
这些问题可以先给：
- 变量框架
- 对照逻辑
- 优先级排序
- 证据等级判断
但不应先替实验直接定具体浓度、时间、转速、温度、波长、进样量。
### 3. 以后需要自动触发“先回文件”的危险问法
- “直接给我一个条件”
- “你帮我定一个浓度/时间/转速/温度”
- “按常规做是不是就行”
- “EPR 一般设多少”
- “PMSO 一般加多少”
- “淬灭剂通常多少倍”
- “HPLC 你直接帮我定流动相”
- “我懒得翻记录，你直接给个差不多的”
### 4. 默认回答原则
以后遇到上述问题，优先采用这条规则：
> 结构可以先帮搭，死数不能顺手替你填。  
> 先回 SOP / 原始记录 / 方法文档；在信息不全时，只给变量框架与对照逻辑，不直接报具体操作值。
### 5. 当前阶段最重要的问答边界
1. **DMPO/TEMP 型 EPR 暂不应被默认当成第一优先主线。**
2. **PMSO 只看消耗、不看 PMSO2，不能上机制结论。**
3. **Na2S2O3 的强抑制不能直接等同于“某单一 ROS 是主导”。**
4. **G3/G4/G5 未完成前，不应把最小机理闭环说成已完成。**
5. **fresh batch 未锁定前，不应把旧样的预实验结果直接当正式主图。**
---
## 一句话 handoff
当前主线不是“把所有机理都测完”，而是先锁定 **Co3O4 / 0.5Ce-Co3O4 主批次**，先拿到**稳定的性能主板**，再用 **DPD-KI + PMSO/PMSO2** 建立最小机理闭环；CeO2、DMPO/TEMP-EPR 和大而全淬灭矩阵都应后置，避免把方法学和支线扩张抢到主线前面。
