# C_stage2_checklist — 初始 Co3O4 / Cu-Co3O4 今日执行清单
## 任务范围
- 目标：按《第二阶段材料合成方法汇总》与《第二阶段实验记录》执行一轮**初始 Co3O4 / Cu-Co3O4**合成。
- 适用路线：**EG + H2O + 尿素 + 160 ℃水热 24 h + 300/400 ℃两段煅烧**。
- 本文件用途：给今天实验台边直接照着走，避免编号混乱、交叉污染和漏记关键数据。
## 样品与统一标号
> 今天建议**只用一套主标号**，不要混用“1号釜 / 3号釜 / B1 / Co / Cu”。
| 样品 | 今日主标号 | 来源中的旧对应关系 | 备注 |
|---|---|---|---|
| 初始 Co3O4 | `CO` | 水热釜 1 = 原始 Co3O4 | 纯 Co 体系 |
| Cu-Co3O4 | `CU` | 水热釜 3 = Cu-Co3O4；制备标号曾写 B1 | 含 Cu 掺杂 |

# 一、按时间顺序 checklist
## Day 1：配液 → 加盐 → 搅拌 → 水热
### 0. 开始前准备
- [ ] 准备 **2 个 100 mL 水热釜内胆**，分别写：`CO`、`CU`
- [ ] 外釜/釜盖同步写：`CO`、`CU`
- [ ] 准备对应搅拌子 2 个
- [ ] 准备称量舟/称量纸并先写好：
  - [ ] `CO-Co`
  - [ ] `CU-Co`
  - [ ] `CU-Cu`
  - [ ] `CO-Urea`
  - [ ] `CU-Urea`
- [ ] 量筒、勺子、药匙确认干净
- [ ] 固定台面位置：**左侧 CO，右侧 CU**
### 1. 向两个内胆分别加入溶剂
#### `CO`
- [ ] 乙二醇 **40 mL**
- [ ] H2O **20 g**
#### `CU`
- [ ] 乙二醇 **40 mL**
- [ ] H2O **20 g**
**容器**：100 mL 水热釜内胆  
**提醒**：两个体系从这一步开始外观就很像；容器上必须已有标号。
### 2. 称 Co 盐并加入对应内胆
#### `CO-Co`
- [ ] 六水合硝酸钴 **1.455 g（5 mmol）** → 加入 `CO`
#### `CU-Co`
- [ ] 六水合硝酸钴 **1.455 g（5 mmol）** → 加入 `CU`
**提醒**：两份钴盐质量完全一样，称量舟不能只写“Co”。
### 3. 只给 `CU` 体系加入 Cu 盐
#### `CU-Cu`
- [ ] Cu(NO3)2·xH2O **94 mg（0.5 mmol）** → 加入 `CU`
- [ ] `CO` **不加 Cu 盐**
**提醒**：Cu 盐记录里注明“易潮解、结块”，要快称、快加、快盖瓶。
### 4. 加搅拌子并初混
- [ ] 向 `CO` 内胆加入对应搅拌子
- [ ] 向 `CU` 内胆加入对应搅拌子
- [ ] 稍微倾斜内胆，**贴壁放入搅拌子**
- [ ] **600 rpm 搅拌 10 min**
### 5. 称并加入尿素
#### `CO-Urea`
- [ ] 尿素 **0.5 g** → 加入 `CO`
#### `CU-Urea`
- [ ] 尿素 **0.5 g** → 加入 `CU`
然后：
- [ ] **600 rpm 继续搅拌约 20 min**
### 6. 水热反应
- [ ] 检查内胆、外釜、盖子标号一致
- [ ] `CO` 与 `CU` 不互换位置
- [ ] **160 ℃，24 h（1440 min）**

## Day 2：转移 → 洗涤 → 干燥
### 7. 先准备离心管
> 来源里“6 个离心管”对应 3 个样品；今天只做 2 个样品，按 2 管/样品准备即可。
- [ ] 准备 **4 个离心管**
- [ ] 依次写好：`CO-1`、`CO-2`、`CU-1`、`CU-2`
### 8. 开釜并转移产物
#### `CO`
- [ ] 将 `CO` 产物转移至 `CO-1`、`CO-2`
#### `CU`
- [ ] 将 `CU` 产物转移至 `CU-1`、`CU-2`
**判据/提醒**：
- [ ] 观察是否“**不粘在水热釜上**”
- [ ] 先做 `CO`，再做 `CU`
### 9. 水洗
- [ ] 去离子水洗 **3–4 次**
- [ ] 记录写法：**高转速 100**
- [ ] 每次离心后小心倒上清，避免沉淀流失
**提醒**：来源明确记录过“**产率太低——离心的时候没注意上清液**”。
### 10. 乙醇洗
- [ ] 乙醇洗 **2–3 次**
- [ ] 记录写法：**慢降下来到 800**
- [ ] 结束判据：**上清液澄清**
> 注：来源里同时还出现过离心机便签“转速800、时间3–5、温度20”等操作信息；与“100 / 800”存在不完全一致。今天上机前必须按实际离心机程序再核对一遍，并把**真实使用参数**记下来。
### 11. 干燥
- [ ] 将洗好的 `CO`、`CU` 分别转入对应烘干容器
- [ ] **55 ℃ 普通烘箱干燥过夜**
- [ ] 干燥结束后称重
**提醒**：来源里专门写过“**一定要看是不是真空干燥**”；本路线原始记录写的是**55 ℃普通烘箱**，但当天仍要现场确认设备模式。

### 12. 煅烧前转移
- [ ] 坩埚/瓷舟先写：`CO`、`CU`
- [ ] 将干燥样品分别转入对应坩埚/瓷舟

# 二、标号和防交叉污染
## 2.1 必须同步写标号的容器
以下容器**都要写**，不能只写一个：
- 水热釜内胆
- 外釜/釜盖
- 称量舟/称量纸
- 离心管（管身为主，必要时盖子也写）
- 烘干皿/表面皿/样品舟
- 坩埚/瓷舟
- 最终样品管
**原则**：样品每换一次“家”，新容器必须先有名字，再装样。
## 2.2 今天建议的最稳操作顺序
- 全流程固定：**先 `CO`，后 `CU`**
- 全程固定空间：**左 `CO`，右 `CU`**
- 任何碰过 `CU` 或 Cu 盐的器具：**不回碰 `CO`**
## 2.3 最容易把样品编号搞混的节点
1. **两个 1.455 g 钴盐称量舟**：外观和质量都一样，最容易混。
2. **0.5 g 尿素分装**：两份完全同质，最容易“拿起就倒”。
3. **离心管只写 1/2 不写母标号**：后面很快会忘记属于谁。
4. **烘干容器和坩埚没提前写字**：转移后再补写，等于靠记忆补证据。
5. **最终样品管重新改名**：会导致与前面记录本编号对不上。
## 2.4 最容易发生交叉污染的节点
1. **Cu 盐称量与加入**：药匙/称量纸回碰 `CO` 会直接污染纯 Co 对照。
2. **开釜转移沉淀**：先碰过 `CU` 再去处理 `CO` 风险最高。
3. **离心洗涤时盖子/管架混放**：容易把 `CO`、`CU` 管弄串。
4. **烘干前湿样转移**：浆料或湿粉挂在勺子、纸片、手套上。
5. **煅烧前粉末转移**：干粉更容易飞散和串样。
## 2.5 漏写/漏分隔的具体后果
| 漏写/失控节点 | 具体后果 |
|---|---|
| 内胆/外釜不写 | 无法确认哪釜是纯 Co、哪釜是 Cu-Co |
| Cu 盐舟不写 | 可能误加、漏加或重复加，纯 Co 对照失效 |
| 离心管只写 1/2 | 分装后立刻失去样品身份 |
| 烘干皿不写 | 干燥后无法确认哪个前驱体进入哪只坩埚 |
| 坩埚不写 | 出炉后样品身份错位，后续表征/活性全错 |
| Cu 器具回碰 CO | “纯 Co3O4”被低水平 Cu 污染，后续比较失真 |
## 2.6 台边极简防错口令
- [ ] 只用 `CO` / `CU` 一套主标号
- [ ] 新容器先写名，再装样
- [ ] 先 `CO` 后 `CU`
- [ ] 左 `CO` 右 `CU`
- [ ] Cu 相关器具不回碰 `CO`
