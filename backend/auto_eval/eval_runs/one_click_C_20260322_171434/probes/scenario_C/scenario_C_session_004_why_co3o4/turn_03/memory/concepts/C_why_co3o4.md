# C_why_co3o4
## id
- C_why_co3o4
## name
- 为什么第二阶段先从 Co3O4 开始
## scope
- 这份 Concept 用于固定 task board 开头的判断边界：为什么当前先以 Co3O4 建 benchmark、为什么不直接进入更复杂体系、以及何时才值得升级到 Ce-Co3O4。
- 目标不是证明 Co3O4 已经是最终最优材料，而是定义当前阶段最稳的推进顺序。

## north_star（一句话）
- 先用 Co3O4 建立可重复、可解释、可升级的基线，再决定是否进入 Ce-Co3O4 复杂化路线。
## notes
### 为什么从 Co3O4 开始
1. **它是当前最合适的 benchmark 母体，而不是先验认定的最终最优材料。**
   - `benchmark rationale` 中，第二阶段 `M-Co3O4` 被视为最接近真实科研任务闭环的样例，天然可以从性能筛选过渡到机制问题。
2. **它兼具“足够简单”和“足够有料”两点。**
   - `why/how` 文件把 Co3O4 放在“结构-电子-缺陷”三层可展开的起点位置：天然双位点、多价态循环、缺陷/掺杂可调、晶格相对稳定。
   - 这类特征支持“先建基线、再做机制验证、再做材料升级”的顺序。
3. **已有实验记录支持它作为当前优先推进对象。**
   - 实验记录显示：在降低浓度后，结果基本吻合，且“基本确定了性能好的材料是 Co3O4”。
   - 这说明 Co3O4 至少已经给出了可继续追踪的性能基线，不是空想起步。
4. **它适合作为后续 Ce-Co3O4 的参照系。**
   - 如果连 Co3O4 的重复性、动力学和关键机制信号都没有讲清楚，那么后续 Ce 掺杂带来的变化就难以归因。
**当前推荐表述：**
> 本阶段先以 Co3O4 建立 benchmark，而不预设其为最终最优材料。
### 不能跳步的原因
1. **复杂体系会同时引入过多变量。**
   - 掺杂、缺陷、晶相、形貌、前驱体残基、煅烧历史和批间波动会一起变化，导致“性能变化来自哪里”难以判断。
2. **现有实验已经暴露出复杂体系的归因风险。**
   - 实验脉络中记录：`0.5 mmol` 多金属掺杂时“基本全部抑制”。
   - 实验记录中又出现了 `Cu-Co3O4` 不同批次之间明显不一致的情况，说明复杂体系本身先带来了合成稳定性问题。
3. **证据标准不允许在基线未稳时直接放大解释。**
   - `project.md` 已明确：
     - `ClO2` 结论至少需要两类证据组合，并配套空白/对照；
     - `Co(IV)` / 高价 Co 需要谱学、探针、淬灭或动力学等组合证据，且要标明证据等级。
   - 因此，在 Co3O4 基线体系尚未完成重复性与关键机制验证前，直接进入 Ce-Co3O4 只会增加解释自由度。
4. **第二阶段当前任务不是“挑出最复杂材料”，而是“先回答值不值得复杂化”。**
   - 先回答：Co3O4 是否稳定可重复？是否出现 ClO2 / 高价 Co 信号？当前瓶颈是什么？
   - 这些问题不清楚，Ce-Co3O4 就没有明确任务目标。
**当前推荐表述：**
> 当前不优先复杂化，先降低归因难度，把 Co3O4 基线做实。
### 升级条件
只有当以下三类信号同时开始出现时，才值得把主线升级到 `Ce-Co3O4`：
#### A. 基线信号：Co3O4 已经站稳
- 活性表现可重复；
- 批间差异在可接受范围；
- 动力学趋势稳定；
- 结构保持和溶出风险已有初步核验。
#### B. 机制信号：出现可继续追证的关键苗头
- `why/how` 文件中的核心问题已经被点明：**高价 Co 有没有形成？ClO2 有没有形成？如果形成了的话，就可以往新范式推动。**
- 但是否“形成”必须遵守 `project.md` 的判据：
  - `ClO2`：至少两类证据组合（如 DPD、UV-Vis、头空间/离子色谱等）+ 关键空白/对照；
  - `Co(IV)` / 高价 Co：谱学、探针、淬灭、动力学等组合证据，且要注明证据强弱。
- 因此，升级不是看到一次好结果就做，而是看到**可重复且可继续补证**的机制信号再做。
#### C. 瓶颈信号：已经知道 Ce 要解决什么问题
- 只有当 Co3O4 已暴露出明确短板时，Ce 掺杂才有任务意义，例如：
  - 活性上限；
  - 选择性不足；
  - 活性物种持续供给不稳；
  - 溶出/循环稳定性；
  - 基质耐受不足。
- 如果还说不清 Ce 是为了解决哪个瓶颈，就不应贸然升级。
**可执行升级判据（task board 可直接引用）：**
- [ ] Co3O4 基线活性重复稳定
- [ ] 至少完成一轮动力学与空白/对照核验
- [ ] 出现 ClO2 的可重复检测信号
- [ ] 出现高价 Co 参与的直接或间接证据苗头
- [ ] 已识别 Co3O4 的明确瓶颈
- [ ] 能明确说明“Ce 是为了解决哪个瓶颈”
### 表述上限（避免写成先验站队）
以下表述不建议直接写进 task 开头：
- “Co3O4 是最优材料”
- “Co3O4 已经证明会形成高价 Co / ClO2”
- “Ce-Co3O4 暂时没有必要做”
更稳的写法是：
- “Co3O4 是当前优先推进的 benchmark 母体”
- “当前任务是验证是否存在 ClO2 / 高价 Co 信号”
- “是否升级到 Ce-Co3O4 取决于基线稳定性、机制信号和已识别瓶颈”
