## 1) 最小闭环目标
### 1.1 这次 task 要回答什么
在你当前 **最佳性能条件** 下，Ce–Co3O4 / NaClO2 体系是否同时满足以下两点：
1. 可重复检测到 **ClO2** 生成；
2. 可重复检测到 **PMSO 被氧化为 PMSO2**，从而支持体系中存在与 **OAT / 高价 Co 通道相符** 的探针响应。
### 1.2 本轮允许得出的结论上限
本轮最多写到：
> 在 Ce–Co3O4 / NaClO2 最佳反应条件下，体系中可检测到 ClO2 生成；同时 PMSO 被转化为 PMSO2。结合空白/对照结果，支持体系中存在与 OAT 型高价 Co 通道相符的氧化过程，并伴随 ClO2 生成。
### 1.3 本轮不允许越界写的结论
- “已直接证明 Co(IV)=O 被观测到”
- “ClO2 是唯一活性物种”
- “机理已完全闭环”
- “PMSO2 的出现就等于直接证明 Co(IV)”
### 1.4 证据门槛
- **ClO2 支路**：DPD-KI 定量 + 标线 + 空白/对照 + 干扰排查
- **PMSO 支路**：PMSO / PMSO2 标线 + 时间曲线 + 空白/对照
- **合并条件**：两条支路必须在**同一套主反应条件**下成立，而不是各跑各的、无法对应

## 2) 实验步骤
### 2.1 任务边界（先把边界定死）
1. 本 task 只做两条最短支路：
   - `ClO2 支路`：DPD-KI / UV-Vis
   - `PMSO 支路`：PMSO → PMSO2 / HPLC
2. **ClO2 支路与 PMSO 支路分开跑反应器**，不要用同一支样同时兼顾所有检测。
3. **本 task 不加入 DMPO/ESR**。理由：方法整理中明确提示 **DMPO 会干扰直接测 ClO2**，因此 DMPO 不能混入当前最小闭环。
4. 本 task 不重新做条件筛选；主反应参数统一使用你当前已选定的“最佳性能条件”。
### 2.2 先填写的主反应参数（执行前补齐）
以下参数必须在开做前填上：
- 催化剂：`[Ce–Co3O4] = ____ g/L`  `（A：当前项目核心参数，必须用你自己的最佳条件）`
- 氧化剂：`[NaClO2] = ____ mM`  `（A）`
- 初始 pH：`____`  `（A）`
- 反应体积：
  - ClO2 支路：`建议 60 mL`  `（B：执行容器建议，不是固定值）`
  - PMSO 支路：`建议 30 mL`  `（B）`
- 温度：`室温/恒温____`  `（A：执行时固定即可）`
- 搅拌条件：`____ rpm 或恒速磁搅拌`  `（A）`
### 2.3 试剂准备
#### 2.3.1 ClO2 分析相关（chlorite核心）
1. **DPD 指示剂** `（A）`
   - 100 mL 配方：
     - DPD：0.44 g
     - 水：89.2 mL
     - 浓 H2SO4：0.80 mL
     - EDTA-2Na（8 g/L）：10 mL
   - 操作：
    1. 先将 DPD 溶于约 70 mL 纯水；
    2. 缓慢加入浓硫酸并混匀；
    3. 加入 10 mL 的 8 g/L EDTA-2Na；
    4. 定容至 100 mL；
    5. 0.45 μm 过滤后，4 ℃ 避光保存，建议 1 周内用完。
2. **KI 溶液** `（A）`
   - 0.5 M KI
   - 参考配置：4.15 g KI / 50 mL
3. **磷酸盐缓冲液** `（A）`
   - pH 6.5
   - 样品和标线必须使用同一批缓冲液
4. **ClO2 标线** `（A）`
   - 若直接购置 ClO2 标液，可优先用外标法
   - 推荐首轮范围：0, 1, 2.5, 5, 7.5 mg/L
   - 样品与标线的显色步骤、加样顺序、读数时间必须完全一致
5. **游离氯干扰排查** `（A）`
   - 预留甘氨酸干扰排查支路
   - 若加甘氨酸前后结果差异明显，则本轮不能把 DPD 响应直接当成“纯 ClO2 定量”
#### 2.3.2 PMSO 支路相关（核心 + 通用方法分开写）
1. **PMSO 与 PMSO2 标准品** `（A）`
   - PMSO（CAS 1193-82-4）
   - PMSO2（CAS 3112-85-4）
   - 分别配独立储备液并做标准曲线
2. **PMSO 投加浓度** `（C）`
   - `1 μM` 只能作为跨体系参考起点，**不是当前 chlorite 体系既定条件**
   - 实际投加原则：
     - HPLC 能稳定量；
     - 不明显扰动 ClO2 主支路。
   - 因此执行时应先做一轮“小剂量试跑 + 扰动检查”后再锁定最终 PMSO 浓度：`____ μM`
3. **HPLC 条件** `（C）`
   - 可先用以下条件试跑：
     - 流动相：30% 乙腈 + 70% 水
     - 流速：1.0 mL/min
     - 检测波长：PMSO 233 nm；PMSO2 217 nm
   - 说明：这只是**通用方法起点**，不是你当前体系已验证条件；若分离度、线性、峰型或基线不理想，应以本机实际方法调整。
4. **淬灭剂** `（C）`
   - 可优先尝试 DMSO 作 PMSO 支路的取样淬灭剂
   - 但必须先验证：
     - 不与 PMSO/PMSO2 峰重叠；
     - 不引入异常基线；
     - 能有效终止取样后继续反应。
### 2.4 反应器设计
#### Reactor A：ClO2 主支路 `（A）`
- 目的：只测 ClO2，不加 PMSO
- 体系：Ce–Co3O4 + NaClO2
- 取样时间：0 / 5 / 10 / 20 / 30 / 60 min
- 每个时间点取样：5.00 mL
#### Reactor B：PMSO 支路 `（A）`
- 目的：测 PMSO / PMSO2
- 体系：Ce–Co3O4 + NaClO2 + PMSO
- 取样时间：0 / 5 / 10 / 20 / 30 / 60 min
- 每个时间点取样：1.0–1.5 mL
### 2.5 最小对照组
至少做以下 4 组：
1. `Main`：催化剂 + NaClO2  `（A）`
   - 测 ClO2
2. `No catalyst`：无催化剂 + NaClO2  `（A）`
   - 测 ClO2；必要时也测 PMSO/PMSO2
3. `No oxidant`：催化剂 + PMSO，无 NaClO2  `（A）`
   - 测 PMSO/PMSO2
4. `Probe group`：催化剂 + NaClO2 + PMSO  `（A）`
   - 测 PMSO/PMSO2
建议再补 1 组：
5. `PMSO interference check` `（A）`
   - 比较“有 PMSO”与“无 PMSO”下的 ClO2 曲线，至少在 10 min 和 30 min 各测一次
### 2.6 ClO2 支路的具体取样与显色
对 Reactor A 每个时间点按以下顺序操作：
1. 取 5.00 mL 反应液；
2. 立即加入 0.75 mL pH 6.5 磷酸盐缓冲液；
3. 加 0.25 mL DPD 指示剂；
4. **最后一步**加入 0.60 mL 0.5 M KI；
5. 混匀后在 **1.0 ± 0.1 min** 时于 **515 nm** 读吸光度。
#### ClO2 支路硬规则
- KI 永远最后加；
- 标线与样品必须同批测定；
- 加 KI 后的等待时间必须统一；
- 不存样、不延迟显色；
- **不在该支路中加入 DMPO**。
### 2.7 PMSO 支路的具体取样与 HPLC 检测
对 Reactor B 每个时间点按以下顺序操作：
1. 取 1.0–1.5 mL 反应液；
2. 立即注入预装过量淬灭剂的取样管；
3. 迅速混匀；
4. 离心或 0.22 μm 过滤去除催化剂颗粒；
5. 上 HPLC 测 PMSO 与 PMSO2。
#### PMSO 支路执行要点
- 取样后必须立即淬灭，避免继续反应；
- 标线最好与样品保持相似基质；
- 若 1 μM 量级无法稳定量，应提高至“刚好可定量的最低浓度”，然后重新做“PMSO 是否扰动 ClO2”的检查。
### 2.8 当天最小检查点
- `CP1`：ClO2 标线性正常，空白无异常显色
- `CP2`：PMSO / PMSO2 标线性正常，峰分离可用
- `CP3`：Main 组 ClO2 随时间变化，而 No catalyst 明显减弱
- `CP4`：Probe group 中出现 PMSO2，而 No oxidant / No catalyst 中很低或无
- `CP5`：PMSO 的加入没有把 ClO2 曲线彻底改写

## 3) 结果判读
### 3.1 满足最小闭环的判据
当以下条件同时满足时，可认为本轮“最小闭环成立”：
1. **ClO2 支路成立**
   - Main 组有可重复的 ClO2 时间曲线；
   - No catalyst 明显减弱；
   - 干扰排查未提示严重游离氯混淆。
2. **PMSO 支路成立**
   - Probe group 中出现可定量 PMSO2；
   - No catalyst / No oxidant 组 PMSO2 很低或无；
   - 至少 PMSO2 一项能稳定量。
3. **两条支路可合并**
   - 两条支路在同一套主反应条件下成立；
   - PMSO 不显著改写 ClO2 主趋势。
### 3.2 四种常见结果情形与写法
#### 情形 A：ClO2 与 PMSO2 都成立
可写：
> 在当前最佳反应条件下，Ce–Co3O4 / NaClO2 体系中检测到 ClO2 生成，同时观察到 PMSO 向 PMSO2 的转化。结合无催化剂/无氧化剂对照，支持体系中存在与 OAT 型高价 Co 通道相符的氧化过程，并伴随 ClO2 生成。
#### 情形 B：有 ClO2，但 PMSO2 很弱或没有
可写：
> 已观察到 ClO2 生成，但 PMSO 探针结果尚不能充分支持 OAT / 高价 Co 通道，本轮不能将该通道作为已成立结论。
下一步优先排查：
- PMSO 投加是否过低；
- HPLC 定量下限是否不够；
- 取样淬灭是否失效。
#### 情形 C：有 PMSO2，但 ClO2 证据不稳
可写：
> 已观察到 PMSO → PMSO2 转化，但 ClO2 定量仍需补充标线与干扰排查，因此现阶段不能将 ClO2 作为已确认产物写入结论。
#### 情形 D：PMSO 一加进去，ClO2 曲线明显改变
可写：
> PMSO 对体系存在明显扰动，因此 PMSO 支路结果只能作为扰动性探针证据，不能直接代表原始无探针体系的反应路径。
下一步：
- 降低 PMSO 投加；
- 重新做 PMSO 扰动检查；
- 必要时将 PMSO 支路降级为辅助证据。
### 3.3 本轮不能写的句子
- “PMSO2 直接证明了 Co(IV)=O 已被观测到”
- “DPD 显色就证明只有 ClO2 存在”
- “DMPO 结果可与本 task 直接合并解释 ClO2”
- “第五阶段机理已经完全闭环”
### 3.4 本轮最小数据包
完成本 task 后，至少应拿到：
1. ClO2 标线原始表；
2. PMSO / PMSO2 标线原始表；
3. ClO2 时间曲线（含对照）；
4. PMSO2 时间曲线（含对照）；
5. PMSO 扰动检查结果；
6. 干扰排查记录（至少说明是否做了甘氨酸检查）。
