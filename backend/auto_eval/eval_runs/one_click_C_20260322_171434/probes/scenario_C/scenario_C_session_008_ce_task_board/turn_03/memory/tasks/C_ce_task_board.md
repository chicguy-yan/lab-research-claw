# C_ce_task_board
> 目标：把 Ce-Co3O4 主线整理成未来两周可执行的 task board，按三条并行任务推进：
> 1. CeO2 / Ce-Co3O4 样品准备
> 2. 性能回测
> 3. 高价钴证据
## 一、必须做
### A. 样品准备线（必须做）
1. **盘点现有样品库存**
   - 确认 `Co3O4`、`0.5Ce-Co3O4`、`CeO2` 是否有库存、是否够两周测试。
2. **补做或确认可用的 0.5Ce-Co3O4**
   - `0.5Ce-Co3O4` 是当前主样品，后续性能线和高价钴证据线都依赖它。
3. **CeO2 至少完成第一轮同底盘合成**
   - 先按与 Ce-Co3O4 接近的底盘条件跑 batch-1，用于判断 CeO2 这条支线是否可用。
4. **对 CeO2 batch-1 做可用性判定**
   - 关注沉淀是否充分、产率是否足够、上清是否异常；该判定本身是后续是否救火的 gate。
### B. 性能回测线（必须做）
1. **先完成 `Co3O4 vs 0.5Ce-Co3O4` 的基线性能回测**
   - 这是当前主线最核心的对比。
2. **补一个不同 `ClO2-` 浓度下的 `Co3O4 vs 0.5Ce-Co3O4` 比较**
   - 优先于“把 CeO2 强行放进主图”。
3. **锁定主样品 + 主反应条件**
   - 后续高价钴证据线正式开跑之前必须完成。
4. **如样品允许，用 fresh batch 复跑核心性能点**
   - 目的：排除旧样漂移，确认主样品可复现。
### C. 高价钴证据线（必须做）
1. **建立 ClO2 的 DPD-KI 方法学**
   - 包括标线、缓冲条件、515 nm 读数流程。
2. **建立 PMSO / PMSO2 方法学**
   - 包括标线、HPLC 分离和取样流程。
3. **正式证据实验只做最小闭环**
   - `Reactor A`：主体系，不加 PMSO，只测 ClO2 时间曲线。
   - `Reactor B`：主体系，加 PMSO，只测 PMSO → PMSO2。
4. **配最小对照组**
   - 至少包含：`No catalyst`、`No oxidant`、`Probe group / interference check`。
---
## 二、依赖关系
### 1. 三条主线的总体依赖
```text
A 样品准备
 ├─> B 性能回测
 └─> C 正式高价钴证据
B 性能回测
 └─> C 正式高价钴证据的“主样品/主条件”锁定
```
### 2. 样品准备线对其他任务的依赖输出
- **A1 库存盘点** → 决定 B 线是否可以先用库存样起跑。
- **A2/A3 可用的 `0.5Ce-Co3O4`** → 是 B 线和 C 线的硬依赖。
- **A4 CeO2 可用性判定** → 只决定 CeO2 是否进入正式对照，不决定主线是否继续。
### 3. 性能回测线的 gating
- **B1/B2 基线性能回测** → 用来判断 `0.5Ce-Co3O4` 是否仍是主样品。
- **B3 `ClO2-` 浓度比较** → 用来确定后续机理实验采用哪套条件更稳。
- **B4 锁定主样品 + 主反应条件** → 是 C 线正式实验的硬前置。
- **B5 fresh batch 复现** → 提升正式证据可信度，但方法学准备不必等待它完成。
### 4. 高价钴证据线的依赖拆分
- **可先并行做的**
  - ClO2 标线
  - PMSO / PMSO2 标线
  - HPLC 条件摸索
  - 干扰检查
- **必须后置的**
  - 正式 `Reactor A / Reactor B` 数据包
  - 正式证据结论整理
- **原因**
  - 正式证据实验必须建立在“主样品 + 主条件已锁定”基础上，避免后面整组数据失效。
### 5. CeO2 的依赖边界
- CeO2 **不是** `Co3O4 vs 0.5Ce-Co3O4` 主性能线的硬前置。
- CeO2 **不是** 高价钴方法学准备的硬前置。
- CeO2 主要影响的是：
 1. 是否能做三样统一对照图；
 2. 是否能用“Ce 单独作用”去增强机理解释。
---
## 三、失败回退路线
### 回退路线 R1：CeO2 不稳定，但 0.5Ce-Co3O4 稳定
**适用情形**
- CeO2 batch-1 沉淀不足、产率低或重复性差；
- 但 `0.5Ce-Co3O4` 可用、`Co3O4` 可用。
**处理策略**
- 主线不后移：
  - 继续推进 `Co3O4 vs 0.5Ce-Co3O4` 性能回测；
  - 继续推进 `ClO2 + PMSO` 方法学；
  - 继续推进以 `0.5Ce-Co3O4` 为主样品的最小高价钴证据。
- CeO2 改为旁路线 rescue：
  - 单独继续优化 CeO2 合成；
  - 暂不把 CeO2 写进核心两周交付。
**需要后移的任务**
- `CeO2 / Co3O4 / 0.5Ce-Co3O4` 三样统一性能图；
- 任何依赖 CeO2 来解释“Ce 单独作用”的结论；
- 任何以 CeO2 为核心对照的增强型机理段落。
**不需要后移的任务**
- `Co3O4 vs 0.5Ce-Co3O4` 基线性能；
- `ClO2-` 浓度比较；
- ClO2 方法学；
- PMSO / PMSO2 方法学；
- 正式高价钴最小证据线（前提：主样品与主条件已锁定）。
### 回退路线 R2：CeO2 不稳定，且 fresh 0.5Ce-Co3O4 也未稳住
**适用情形**
- CeO2 不稳定；
- 同时 `0.5Ce-Co3O4` 新样也没准备好，导致主样品/主条件无法锁定。
**处理策略**
- 样品准备线优先补 `0.5Ce-Co3O4`；
- 性能线先保留库存样预跑/摸底；
- 高价钴线只保留方法学准备，不做正式数据包。
**必须整体后移的任务**
- fresh batch 的性能复现；
- 正式 `Reactor A / Reactor B`；
- 任何基于“本周已锁定主样品和主条件”的正式结论。
**仍可继续的任务**
- CeO2 batch-2 救火；
- DPD-KI 标线；
- PMSO / PMSO2 标线；
- HPLC 条件摸索；
- 空白体系的方法学预实验。
### 回退路线 R3：CeO2 连续两轮不稳，但必须保留 Ce 单独对照
**适用情形**
- 研究叙事上强烈希望保留 CeO2 对照；
- 但 CeO2 batch-1 和 batch-2 都不稳定。
**处理策略**
- 明确把目标从“正式机理数据包”降级为“主样品性能锁定 + CeO2 救火 + 方法学准备”；
- 高价钴证据线先不追正式成图。
**代价**
- 两周主线推进速度下降；
- 三样统一图、Ce 单独作用判断、增强型机理解释都将被拖慢。
**建议**
- 若两轮 CeO2 仍不稳，应暂停其作为正式对照的角色，转回 R1，不要让 CeO2 长期卡住 Ce-Co3O4 主线。
---
## 四、哪些任务在 CeO2 不稳定时需要整体后移
### 不需要整体后移
- `Co3O4 vs 0.5Ce-Co3O4` 主性能线；
- `ClO2-` 浓度比较；
- ClO2 方法学准备；
- PMSO / PMSO2 方法学准备；
- 以 `0.5Ce-Co3O4` 为主样品的最小高价钴证据线。
### 需要部分后移
- CeO2 纳入统一性能图；
- 用 CeO2 做辅助机理对照；
- 以 CeO2 为对象补跑淬灭或辅助证据。
### 必须整体后移
- `CeO2 / Co3O4 / 0.5Ce-Co3O4` 三样同批、同条件、同轮次的正式比较图；
- 依赖 CeO2 来支撑“Ce 单独贡献”的正式结论；
- 若 `0.5Ce-Co3O4` 本身也未稳住，则正式高价钴 Reactor A/B 整体后移。
---
## 五、执行建议（两周内的默认优先级）
### 默认优先级顺序
1. 先保住 `0.5Ce-Co3O4` 主样品；
2. 再锁定 `Co3O4 vs 0.5Ce-Co3O4` 的性能差异；
3. 再开 `ClO2 + PMSO` 最小高价钴证据；
4. CeO2 作为重要但非绝对前置的支线推进。
### 一句话原则
> 真正会导致高价钴正式证据线整体后移的，不是 CeO2 失败本身，而是 `0.5Ce-Co3O4` 主样品未锁定、或主反应条件未锁定。
