# C_chapter_dependency
> 目的：把“实验任务”提前挂到“写作章节”，同时标明各章节的前置实验、数据处理、关键对照、共用方法，以及在 direct proof 暂时不足时的可写上限。
## 第一章
## 1. 章节定位
**建议章名（保守写法）**：
- 高价钴选择性生成的支持性证据构建
- 或：Ce–Co3O4/NaClO2 体系中高价钴相关氧转移通道的支持性证据
**核心问题**：
1. 体系中是否存在与高价钴相关的氧转移通道
2. 体系中是否伴随 ClO2 生成
3. 这些现象是否可在**无污染物体系**下独立成立
## 2. 章节依赖的实验
### 2.1 无污染物反应体系
- 催化剂 + NaClO2 + 水/缓冲液
- 不引入苯酚等污染物
- 目的：减少副反应路径，让 Co(IV)/ClO2 证据更干净
### 2.2 ClO2 检测
- DPD-KI 显色法
- 515 nm 定量
- 需要标准曲线、时间曲线、空白与对照
### 2.3 高价钴相关探针
- PMSO → PMSO2
- HPLC 定量 PMSO/PMSO2
- 可做时间曲线、终点比较、条件依赖
### 2.4 增强证据（有条件再补）
- EPR
- ^18O 标记
- 原位/准原位谱学
### 2.5 条件依赖实验
- pH 梯度
- 催化剂投加量
- NaClO2 投加量
- 时间演化
## 3. 数据处理与图件输出
- ClO2 标准曲线与时间曲线
- PMSO/PMSO2 定量图
- 条件依赖比较图（pH / 剂量 / 时间）
- 如适用，可用 GraphPad 统一拟合与作图风格
## 4. 关键对照组
- 无催化剂
- 无 NaClO2
- 仅催化剂
- 仅 NaClO2
- pH 对照
- 显色空白/方法空白
- PMSO 自身空白与干扰排查
## 5. 当前可写上限（direct proof 不足时）
### 可先写为 supporting evidence 的内容
- DPD-KI 结果**支持**体系中存在可检测 ClO2 的形成
- PMSO→PMSO2 结果**支持**存在与 OAT 型高价钴相关的氧转移过程
- pH/时间/剂量依赖结果**进一步支持**该过程与催化剂活化 NaClO2 有关
### 暂时不能写满的内容
- “已直接证明 Co(IV)=O 被观测到”
- “已完全证实高价钴被选择性生成”
- “仅凭 DPD 或 PMSO 即完成机理定案”
### 建议留白位点
- 高价钴直接证据（待 EPR / ^18O / 原位谱学补充）
- ClO2 的正交验证（待 UV-Vis 特征吸收 / IC / 头空间等补充）

## 第二章
## 1. 章节定位
**建议章名**：
- 苯酚降解活性图、动力学与淬灭筛查
- 或：Ce–Co3O4/NaClO2 体系下苯酚去除行为及活性物种辅助判别
**核心问题**：
1. 苯酚去除效率和动力学如何随材料与条件变化
2. 活性图如何支撑材料筛选与条件窗口
3. 淬灭实验能把活性通道限定到什么程度
4. 第二章结果如何回扣第一章的高价钴/ClO2 主线
## 2. 章节依赖的实验
### 2.1 苯酚基线降解实验
- 设定初始浓度
- 定时取样
- HPLC 测定 Ct
- 输出去除率曲线
### 2.2 活性图 1：不同负载量
- 固定催化剂投加量
- 比较不同材料/不同负载量
- 输出时间曲线与 kobs 比较
### 2.3 活性图 2：不同催化剂投加量
- 固定苯酚浓度与 NaClO2 浓度
- 改变催化剂量
- 输出时间曲线与 kobs 比较
### 2.4 活性图 3：不同 NaClO2 投加量
- 固定苯酚浓度与催化剂量
- 改变 NaClO2 投加量
- 输出时间曲线与 kobs 比较
### 2.5 淬灭剂实验
- 以代表性条件为基础
- 做淬灭前/后的苯酚降解对比
- 输出终点去除率与 kobs 变化
## 3. 数据处理与图件输出
- 原始浓度-时间曲线
- 伪一级动力学拟合
- kobs 汇总图
- 活性图（负载量 / 催化剂量 / NaClO2 剂量）
- 淬灭剂影响对比图
## 4. 关键对照组
- 无催化剂
- 无 NaClO2
- 仅吸附
- 仅 NaClO2 + 苯酚
- 无淬灭剂基线
- 淬灭剂自身干扰对照
## 5. 当前可写上限（direct proof 不足时）
### 可先写为正文主结果的内容
- 苯酚去除率与 kobs
- 不同负载量/投加量/NaClO2 条件下的系统性变化
- 活性图的排序与条件依赖
### 可先写为 supporting evidence 的内容
- 淬灭结果**提示**多条活性通道可能共同参与苯酚去除
- 第二章活性与淬灭趋势**与第一章 supporting evidence 在方向上相一致**
### 暂时不能写满的内容
- “某单一活性物种为唯一主导路径”
- “已完成 Co(IV) / ClO2 / 自由基贡献比例的定量拆分”
- “第二章单独完成机制闭环”
### 建议留白位点
- 主导活性物种排序
- 各路径贡献率
- 基于淬灭剂的最终定案表述

## 共用方法与卡点
## 1. 两章共用的方法平台
### 1.1 体系与实验设置
- 催化剂合成与基础表征
- NaClO2 配制与浓度控制
- pH 控制
- 取样时间点设计
- 反应终止/淬灭流程
### 1.2 分析检测平台
- HPLC：苯酚、PMSO、PMSO2
- UV-Vis：DPD-KI 法检测 ClO2
- IC/HPIC：阴离子分析（如 ClO2− / ClO3− 等）
- EPR：高价钴/活性物种辅助证据
### 1.3 数据处理平台
- GraphPad 做伪一级动力学拟合
- 统一 kobs 输出
- 统一图形格式与多组条件比较
## 2. 两章共用的对照逻辑
- 无催化剂
- 无 NaClO2
- 仅催化剂
- 仅氧化剂
- pH 对照
- 方法空白与显色空白
- 探针/淬灭剂自身干扰排查
## 3. 章节之间的依赖关系
- 第一章先提供**无污染物体系下的 supporting evidence**：ClO2 与高价钴相关氧转移通道
- 第二章再提供**苯酚体系中的功能性响应**：活性图、kobs、淬灭趋势
- 第二章的解释边界受第一章约束；第一章的机制意义可由第二章的活性结果获得侧向支撑
## 4. 当前主要卡点
### 4.1 第一章卡点
- 高价钴 direct proof 缺失时，章节标题与结论必须降级为 supporting evidence
- ClO2 若只有单一 DPD 证据，结论上限不能过高
### 4.2 第二章卡点
- 苯酚初始浓度、代表性条件尚需固定
- “不同负载量”具体定义需统一（材料组成/负载比例/掺杂水平）
- 淬灭剂矩阵需要配套干扰排查，否则解释容易越界
### 4.3 共用卡点
- 取样时间点必须能同时支撑第一章探针/显色与第二章动力学拟合
- GraphPad 模板应提前统一，否则后续多图整合会返工
- 若要把 supporting evidence 升级为更强结论，优先补：
 1. EPR 或准原位谱学
 2. ^18O 标记
 3. ClO2 的正交检测方法
 4. 淬灭剂自身干扰对照
## 5. 当前建议的写作策略
- 第一章先写：方法 + DPD + PMSO + 条件依赖 + 证据等级声明
- 第二章先写：苯酚性能 + kobs + 活性图 + 淬灭筛查 + 谨慎讨论
- 所有“直接证明”“唯一主导”“选择性生成已证实”类表述，统一留待 direct proof 补齐后再升级
