# Proposal Revision Matrix

## 版本差异

### 1) 版本序列与定位

| 版本 | 文件 | 版本定位 | 这一版主要在做什么 |
|---|---|---|---|
| 准备脉路 | `assets/uploads/f1494f0d_【开题报告准备脉路】.md` | 前期筹备便签 / 工作流草图 | 先定义开题准备流程：文献意群检索、分章节推进、最后汇总成 PPT |
| 范本 markdown | `assets/uploads/b807daff_【开题报告】.md` | 学院/组内模板骨架 | 给开题报告提供标准结构：背景、进展、内容、路线、方法、进度、进展 |
| 重构版 markdown | `assets/uploads/ae04a4a8_【开题报告】.md` | 研究叙事模板 | 把模板改造成真正可写的 scientific story，强调“事实 + 空白 → 研究目的/路线” |
| V3 PPT | `assets/ppt_pack/76bb19d2_开题报告-颜雍颀-V3.pptx` | 答辩版故事压缩 | 将主线压缩为可讲述的项目故事，锁定 chlorite-based AOPs、Co3O4、抗生素选择性氧化与机制问题 |
| final docx | `assets/uploads/fde1237c_开题报告-颜雍颀(1).docx` | 正式书面 proposal | 将答辩故事回填为规范、可提交、可审查的正式文本 |

### 2) revision sense 视角下的版本推进

| 版本 | 主要在补什么 | 主要在删什么/弱化什么 | 科学主张如何收紧 |
|---|---|---|---|
| 准备脉路 | 补“怎么开始做开题”：文献意群、章节拆分、时间线 | 基本未进入具体 scientific claim | 还没有真正的科学主张，只是把任务收紧为“先搭框架再写” |
| 范本 markdown | 补标准开题格式骨架 | 删除前期脑暴的开放性，强制回到学院结构 | 主张只收紧到“必须把问题、内容、路线写齐”，仍未锁定具体体系 |
| 重构版 markdown | 补完整研究叙事：对象性质—污染风险—技术全景—主线工艺—材料设计—研究目的/路线 | 弱化模板式填空，不再让“时间安排/工作进展”主导主线 | 从“开题要写什么”收紧为“每一节都要通向一个可研究空白” |
| V3 PPT | 补具体课题：antibiotics → chlorite-based AOPs → heterogeneous route → Co3O4 → doped Co3O4；补 selective oxidation、reactive species、matrix、已有进展、PMSO/DPD/DFT 等机制工具 | 删掉大量泛综述枝杈与大而全铺垫 | 从“要做某种 AOP”收紧为“研究 Co3O4 活化 chlorite 对抗生素的选择性氧化及其机理” |
| final docx | 补规范章节、文献回顾、研究目标/内容/方法/表征/理论/进度，并把已有结果写成正式 proposal 语言 | 弱化 PPT 式口头感和过强判断 | 从“我大概知道机制是什么”收紧为“我要阐明 dominant sites / reactive species / selective oxidation mechanism / matrix effect / application closure” |

## 增强项

### A. 哪些地方是“写得更锋利了”

1. **从任务语言变成问题语言**
   - 准备脉路阶段关注的是“怎么搜、怎么分章节、怎么汇总”。
   - 到重构版 markdown 开始，文本开始回答“为什么这个问题值得做、现有研究哪里不够”。

2. **从技术全景变成主线路线**
   - 范本与重构版仍带有综述/模板属性。
   - 到 V3 PPT，路线明显聚焦为 `chlorite-based AOPs`，这是一次真正的聚焦化修订。

3. **从泛催化剂讨论变成特定位点问题**
   - V3 PPT 将材料主线压缩到 `spinel Co3O4`，并把问题收紧到 `tetrahedral Co2+ / octahedral Co3+` 与活化位点的关系。
   - 这一步不是简单压缩，而是把“改性有效”推进为“哪类位点主导活化仍不清楚”。

4. **从“要做机理”变成“要分清哪几类机理变量”**
   - 后期版本已将机理拆成：dominant active sites、reactive species coexistence、diverse antibiotics selective oxidation、matrix effects。
   - 这让课题从泛泛“机理研究”变成更可追问、可设计实验的问题集。

5. **从口头性结论转向可审查的研究目标**
   - final docx 的强化不在于更大胆，而在于更规范：使用“阐明 / 揭示 / 评估”等目标动词，降低“像既成事实”的句子比例。

### B. 哪些地方其实只是“删掉了含糊表述”

1. **删掉模板话**
   - 重构版 markdown 将学院式标题话术改写为“事实—不足—研究目标”的叙事结构。
   - 这是表达去噪，不等于新增证据。

2. **删掉大而全铺陈**
   - V3 PPT 剪掉了大量通用污染物、处理工艺、材料策略的枝杈，只保留服务主线的内容。
   - 这让故事更集中，但本质是边界清理。

3. **删掉过强的口头判断**
   - 从 PPT 中偏像定论的“Co(IV)=O 选择性攻击 antibiotics”“lower DBPs → safety”，过渡到 final docx 中更谨慎的“需要阐明”“需要验证”“需要评价”。
   - 这是口径净化，不是证据升级。

4. **删掉泛泛应用口号**
   - final docx 用 `complex water matrix / toxicity analysis / stability / continuous-flow validation` 替代模糊的“应用前景好/安全性更高”。
   - 这属于把大话拆成可检查的评价维度。

## 仍需修补

### A. 当前仍存在的逻辑跳跃

1. **“选择性氧化”论证仍有跳跃**
   - 现有叙事常从“antibiotics 含富电子位点”与“chlorite/ClO2 倾向攻击富电子位点”直接跳到“本体系对 antibiotics 具有选择性优势”。
   - 中间仍缺：不同类别抗生素的结构—反应性对比、与 DOM/无机离子竞争下的选择性保持、去除率之外的真正选择性指标。

2. **“Co(IV)=O”论证仍有跳跃**
   - 目前的链条常是：文献先例提示 Co3O4/掺杂可促进高价态钴 → 可用 PMSO/DPD/DFT 做机制分析 → 因而本体系能分辨 ClO2 与 Co(IV)=O 的贡献。
   - 还缺：PMSO 的特异性边界、DPD 对 ClO2 的适用边界、以及二者如何与底物降解贡献联立判定，而不只是平行罗列。

3. **“Ce 掺杂为何最优”仍缺证据桥**
   - 现有结果说明 Ce-Co3O4 表现更好，但“性能最好”并不自动等于“关键位点/电子结构被有效重塑”。
   - 中间还需要连接：Ce/Co 价态联动、氧空位/配位重构、以及是否真正改变了 dominant site，而不只是比表面积或形貌改善。

4. **“应用闭环”仍偏愿景化**
   - 文稿已开始引入 matrix、toxicity、stability、continuous-flow，这是进步。
   - 但目前更像“应该评估什么”，尚未充分回答“为什么这条技术相对其他路线更适合应用”。

### B. 下一轮最值得补的修订动作

1. 在“选择性”部分加入**结构—反应性—竞争底物**三联证据框。
2. 在“活性物种”部分把 **PMSO / DPD / quenching / kinetics / product distribution** 串成判定流程，而不是并列工具箱。
3. 在“Ce 掺杂”部分补一段**性能提升 ≠ 位点归属成立**的边界声明，再给出拟采用的判据。
4. 在“应用前景”部分避免直接写“更安全/更适合工程化”，改写为**待通过副产物、毒性、稳定性、连续流表现综合评估**。

### C. 一句话总结

这组版本演化的核心，不是“字越来越多”，而是：
**从准备流程 → 模板骨架 → scientific story → 答辩故事 → 正式 proposal**，同时把很多“像结论的话”改写成“可被验证的研究目标”；但位点—物种—选择性—应用四条桥梁之间，仍有若干逻辑空档需要下一轮继续补齐。
