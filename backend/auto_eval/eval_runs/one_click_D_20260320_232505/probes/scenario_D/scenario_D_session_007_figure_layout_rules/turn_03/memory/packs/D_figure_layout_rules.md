# D figure layout rules
## 目的
基于以下 3 份素材，提炼一套可复用到 thesis / 组会汇报的图文排版规则，重点回答：
- 图-文比例怎么定
- 图注与脚注怎么写
- 信息层级与页内逻辑流怎么组织
- 哪些页面虽然“做得很满”，但实际上不利于口头讲述与结论传达

## 排版规则
### 1. 总原则
- 一页只服务 **1 个主 claim**，不要同时承担“结构 + 活性 + 机理 + 应用”四个任务。
- 标题负责写结论，图负责给证据，脚注负责给边界。
- 页面优先顺序不是“我先做了什么实验”，而是“读者应该先看懂什么”。
- 真正有效的页应做到：**一眼能看出主图，10 秒能明白主旨，30 秒能讲完主逻辑。**
### 2. 图-文比例
#### 2.1 结果汇报页
- 推荐视觉比例：**图 65–75% / 文字 15–25% / 脚注与留白 5–10%**。
- 主图区应占页面中上部约 2/3。
- 一页优选 **2–4 个 panel**；超过 4 个 panel 通常说明应拆页。
#### 2.2 背景/综述页
- 推荐视觉比例：**图 50–60% / 文字 25–35% / 脚注 10% 左右**。
- 可适当增加解释性文字，但仍应以图先行，不建议做成大段正文页。
#### 2.3 thesis 图版
- 推荐视觉比例：**图 80–90% / 图内文字 5–10%**。
- 图版尽量只保留 panel 标号、坐标轴、图例、必要峰标与箭头。
- 详细解释放在 caption 与正文，不要把 PPT 式长句直接塞进图里。
### 3. 信息层级
建议固定为 4 层：
#### Level 1：页标题 / 主 claim
- 一页只能有 1 个。
- 标题应是结论句，而非方法名。
- 例如：
  - 好：`Ce0.5-Co3O4 shows the highest chlorite activation activity`
  - 差：`Performance Evaluation`
#### Level 2：panel 组标题
- 用于标记证据分组，如 `SEM`、`XRD`、`Quenching`、`PMSO probe`。
- 只做分组，不抢主标题的位置。
#### Level 3：图内关键标注
- 只标最关键的 1–3 处：峰位、箭头、关键样品、趋势方向。
- 不要把每一个峰、每一个点都标满。
#### Level 4：脚注 / 来源 / 条件
- 放页底，统一弱化呈现。
- 承担最小可复现信息，而不是承担主结论。
### 4. 页内逻辑流
建议所有结果页都按：
**标题（题眼） → 中部图证据 → 一句结论 → 底部脚注**
#### 4.1 表征页
- 推荐顺序：**形貌/相结构 → 界面证据 → 局域电子态/缺陷证据 → 一句结构结论**
- 结构页只说“提供结构基础”，不要直接越级到“因此已证明高价钴生成”。
#### 4.2 活性页
- 推荐顺序：**主动力学曲线 → 定量比较（kobs/柱状图） → 必要对照 → 条件脚注**
- 标题要回答“谁最好、强多少”，而不是“做了活性评价”。
#### 4.3 机理页
- 推荐顺序：**先排除 → 再支持 → 最后综合**。
- 可按：淬灭/排除证据 → PMSO/EPR 等支持证据 → 机制示意图 summary。
- 机制示意图只能做收束，不能替代证据图。
#### 4.4 应用/边界页
- 推荐顺序：**参数窗口 → 抗干扰/实际水体 → 稳定性/浸出**。
- 结论应写“适用窗口与边界”，不要轻易拔高为“普适应用”。
### 5. thesis 与汇报的统一规则
#### 共用部分
- 共用同一条证据主线。
- 共用同一种样品命名和颜色逻辑。
- 共用同一 panel 顺序与主 claim 结构。
#### 差异部分
- **汇报**：标题更结论化，脚注更完整，可保留一句 takeaway。
- **thesis**：图内尽量少字，更依赖 caption；不保留 PPT 式装饰元素。
### 6. 可直接执行的版式纪律
- 一页一个主句。
- 一页只回答一个问题。
- 主图大、辅图小、总结最短。
- 同一类页使用同一视觉语法。
- 高亮颜色只服务关键样品与关键物种，不要每页换逻辑。

## 图注脚注规则
### 1. 图题 / 页标题规则
#### 1.1 核心原则
- 图题要写“这页证明什么”，不是“这页用了什么方法”。
- 方法名更适合放在二级标题或 panel 标题中。
#### 1.2 推荐句式
- 结构页：`Ce incorporation creates interfacial perturbation and stronger OV-related features`
- 活性页：`Ce0.5-Co3O4 delivers the best activity under the standard condition`
- 机理页：`Quenching and PMSO tests support a high-valent cobalt route`
- 应用页：`pH and matrix ions define the practical operating window`
#### 1.3 结论上限纪律
- 证据不足时，使用：`support`、`suggest`、`is consistent with`、`indicate`。
- 不要把相关性写成“已证明唯一机理”。
### 2. 脚注承担的 3 类信息
#### 2.1 实验条件脚注
用于活性页、淬灭页、EPR 页、pH 页、循环页等。
推荐格式：
`Conditions: 60 mL, 10 mg L⁻¹ SMX, 0.1 mmol L⁻¹ NaClO₂, pH 7, catalyst 0.5 g L⁻¹, unless otherwise noted.`
要求：
- 一页只写一遍。
- 放页底固定位置。
- 多个子图条件相同，不要每个 panel 都重复写。
#### 2.2 文献来源脚注
用于综述页、借用文献图页。
推荐格式：
`Source: Chem. Eng. J., 2023, 452, 139103.`
要求：
- 给最小必要来源即可。
- 不要把 DOI、链接大段堆在主体区。
- 文献来源是脚注，不是主内容。
#### 2.3 缩写/特殊说明脚注
用于首次出现的关键缩写、探针、判据。
例如：
`PMSO oxidation to PMSO₂ is used here as an OAT probe.`
要求：
- 缩写首次出现时解释 1 次。
- 后续可直接沿用。
### 3. 不建议的脚注写法
- 把主结论写进脚注。
- 把实验条件写成 3 行以上小论文。
- 同一页不同子图条件不一致却不说明。
- 只有文献来源，没有本页关键条件。
- 把重要限定信息藏在很小、很浅、投影时看不清的字里。
### 4. thesis 与汇报中的脚注区别
- **汇报**：脚注更重要，因为听众不会自动知道实验条件。
- **thesis**：条件可适度简化，详细说明可交给 caption 与 Experimental；但关键比较页仍建议保留一句限定条件。

## 常见错误
### 1. 信息密度失衡
#### 1.1 一页塞 6–9 张图，每张都很小
- 表面上显得“做了很多”。
- 实际上没有主图，听众看不清，记不住。
- 改法：保留 1 个主图 + 2–3 个辅图，其余拆页或放补充页。
#### 1.2 图很多，字也很多
- 图和文字互相抢注意力。
- 读者不知道先看哪里，口头讲时也容易来回跳。
- 改法：图负责证据，标题负责结论，文字只留一句总结和一行脚注。
#### 1.3 所有图一样大
- 排得整齐，但没有主次。
- 看起来平均，实际等于没有重点。
- 改法：主图放大，辅助图缩小。
#### 1.4 一页同时讲结构、活性、机理、应用
- 表面上逻辑完整。
- 实际上每个结论都没讲透。
- 改法：拆分为不同论证页。
### 2. 图和结论不匹配
#### 2.1 标题写“证明机制”，图只给相关性
- 典型表现：标题过满、证据过弱。
- 改法：把标题降级为 `support` / `suggest` / `consistent with`。
#### 2.2 用机制示意图替代证据图
- 示意图只是解释，不是证据。
- 改法：真实数据图先行，示意图放最后做收束。
#### 2.3 图只支持局部现象，标题却写总体结论
- 例如只测一个 pH，却写“适用范围广”；只测一个污染物，却写“具有普适性”。
- 改法：标题范围必须与证据范围一致。
#### 2.4 缺关键对照，却下强结论
- 常见缺口：blank、无催化剂、无氧化剂、吸附对照、均相/溶出排除。
- 改法：结果页至少出现最关键的一组对照；没有时不要把话说满。
#### 2.5 图里关键点没标出来
- 原图很完整，但读者不知道该看哪里。
- 改法：只高亮 1–3 个真正关键的位置。
### 3. 脚注不足或失真
#### 3.1 页底没有条件脚注
- 页面看起来很干净，但 claim 没边界。
- 老师第一句通常就会问“什么条件下？”
#### 3.2 同页不同子图条件不一致却没说明
- 读者默认这些图可以横向比较，容易造成误读。
#### 3.3 文献图没有来源，或来源太隐蔽
- 学术规范风险高。
- 改法：在页底固定来源区。
#### 3.4 缩写、探针、判据首次出现不解释
- 页面只有作者自己能读懂。
- 尤其高风险于：PMSO、FFA、TBA、p-BQ、OAT、EPR。
#### 3.5 把限定信息藏进几乎看不见的小字
- 看似高级，实则不可读。
- 脚注可以弱化，但不能不可见。
### 4. 根本不适合口头讲
#### 4.1 标题是名词，不是句子
- 如 `XPS analysis`、`Mechanism study`。
- 这类标题不利于口头开场，也无法直接传递结论。
#### 4.2 页面的阅读顺序不自然
- 听众不知道先看左上、右上还是中间。
- 改法：固定左上到右下的阅读路径，分组顺序服从讲述顺序。
#### 4.3 一页有 3 个 take-home messages
- 听完以后通常一个也记不住。
- 改法：一页只保留 1 个主消息。
#### 4.4 需要你讲 2 分钟，页面本身才勉强看懂
- 页面自解释性太差。
- 改法：先做“5 秒测试”：不听讲，别人能否看出这页主旨。
#### 4.5 字太小，讲述变成“寻找细节”
- 典型信号：你自己总说“这里字比较小”。
- 改法：投影时读不清的字，默认等于没写。
#### 4.6 过度依赖动画
- 静态页一旦导出 PDF 或现场卡顿，逻辑就会崩。
- 改法：先保证静态页成立，再考虑动画辅助。
### 5. 高危页型
#### 5.1 大而全综述拼盘页
- 6 张文献图 + 多个箭头 + 多个来源。
- 更像资料墙，不像论证页。
#### 5.2 方法罗列页
- 把 XRD、XPS、TEM、SEM、BET 全写在一页。
- 只说明“测了什么”，没有说明“发现了什么”。
#### 5.3 想一步讲完机制页
- 淬灭、EPR、探针、电化学、示意图全堆一页。
- 最容易失控，也最容易被质疑结论过界。
#### 5.4 论文截图直接搬到汇报页
- 论文图适合静读，不适合口头汇报瞬时理解。
- 改法：汇报页应重新做一版，而不是直接截图粘贴。
### 6. 30 秒自检卡
每做完一页，至少检查以下 6 条：
1. 标题是不是一句结论？
2. 主图是不是一眼就能认出来？
3. 图块顺序是不是按证据链，而不是按实验时间顺序？
4. 脚注有没有写清最小条件/来源？
5. 我能不能在 30 秒内讲完这页主逻辑？
6. 不听我讲，别人能不能看懂这页大意？
若其中有 2 条答“不能”，这页通常就应重排。

## 一句话收束
最稳妥的图文排版原则是：**一页一个 claim；图证明 claim；脚注限制 claim。**
