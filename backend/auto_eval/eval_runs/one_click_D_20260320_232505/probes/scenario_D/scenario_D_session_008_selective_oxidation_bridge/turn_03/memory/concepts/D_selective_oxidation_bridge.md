# selective oxidation / polymerization 讨论桥
## 目的
将 selective oxidation / polymerization 这条旁支收束为 thesis 中可安全使用的 discussion bridge，区分：
1. 哪些内容可以进入正文写作；
2. 哪些内容只能作为讨论启发；
3. 哪些高风险说法需要自动降级，避免把文献先例或间接证据写成“本体系已观察到”。
## 适用边界
- 当前对象：Ce-Co3O4 / NaClO2 - SMX 相关 thesis 讨论桥
- 当前用途：discussion bridge，而非主机制结论
- 当前证据边界：现阶段更稳的是“选择性氧化语境 + 潜在竞争去向”，不稳的是“本体系已发生 polymerization”
---
## 可进入写作的桥
### 1. 可写成正文的核心桥句
- 本体系现有结果更适合放在 **selective oxidation** 的讨论框架中，而不是直接放进“彻底矿化”框架。
- 文献表明，在高价金属/非自由基氧化体系中，污染物去除并不必然对应完全矿化，而可能在 **进一步氧化** 与 **偶联/聚合式去向** 之间分配。
- 氧化剂供给水平与底物电子性质，可能共同影响 selective oxidation 的具体表现。
- 因此，在 thesis 讨论中可以将 polymerization 引入为 **文献支持下的潜在竞争路径**，用于扩展对 selective oxidation 命运分配的理解。
### 2. 适合进入正文的表述边界
这些说法可以写，但应保持保守：
- “现有结果提示本体系可能涉及具有一定选择性的氧化过程。”
- “相关文献显示，选择性氧化体系中污染物去除可表现为进一步氧化与偶联/聚合并存或竞争的路径分配。”
- “底物结构与电子性质可能影响该类反应的路径表达。”
- “结合相关先例，除进一步氧化外，不排除部分中间体存在其他去向。”
### 3. 推荐正文定位
- 放在 **Discussion 末段** 或 **Mechanistic implications** 小节末尾。
- 作用是：
  - 帮主线 selective oxidation 增加深度；
  - 展示对文献分支的掌握；
  - 但不把 thesis 主线改写成“已证实 polymerization 机制”。
### 4. 建议正文模板
> 本体系现有结果提示，Ce-Co3O4/NaClO2 对 SMX 的去除可能涉及具有一定选择性的氧化过程。值得注意的是，近年来相关研究表明，在高价金属或非自由基氧化体系中，污染物去除并不必然对应完全矿化，而可能在进一步氧化与偶联/聚合等不同去向之间分配。特别是，氧化剂供给水平与底物电子性质可共同影响这一分配方式。然而，这类现象在不同氧化剂-催化剂组合中的可迁移性仍需谨慎评估。由于本研究尚缺少针对聚合产物、表面沉积及碳去向的直接证据，本文不将 polymerization 作为已证实路径，而仅将其作为 selective oxidation 讨论中的潜在竞争去向与后续验证方向。
---
## 只适合作讨论的桥
### 1. 只能作为启发、不能上升为正文结论的内容
- **Ce 掺杂可能影响电子结构，从而改变高价钴生成或路径分配。**
- **NaClO2 剂量可能像部分过硫酸盐体系那样调节 deeper oxidation / polymerization balance。**
- **SMX 也许存在 coupling / oligomerization side-path。**
- **若存在聚合式去向，可能改变氧化剂利用效率或副产物分布。**
### 2. 这些内容为什么只能写成讨论
因为当前本体系仍缺：
- 聚合/偶联产物直接鉴定；
- 催化剂表面有机沉积证据；
- TOC 与母体去除不同步证据；
- 路径分配随条件变化的系统矩阵；
- Ce 调控 Co 电子结构或高价态生成的直接谱学支持。
### 3. 适合的降级写法
- “Ce 掺杂对电子结构及高价钴生成的具体影响仍需进一步结合谱学证据确认。”
- “未来可进一步考察氧化剂投加量是否会改变本体系中间体的后续去向。”
- “若后续发现 TOC 与母体去除不同步，或催化剂表面有机沉积增强，则需进一步评估偶联/聚合路径的可能性。”
- “相关文献提示存在与聚合相关的反应去向，但该点在本体系中尚待验证。”
### 4. 讨论层可保留的 3 个 claim
1. 本体系更像 selective oxidation 语境，而不是简单自由基矿化语境。
2. 文献表明 selective oxidation 体系中存在 deeper oxidation 与 coupling/polymerization 的竞争去向。
3. 本体系目前尚不足以将 polymerization 写成已证实路径。

## 风险语句
### 1. 总规则
只要一句话满足以下任一条件，就应自动降级为“可能相关 / 可启发 / 待验证”，而不是写成“本体系已观察到”：
- 关键依据来自文献，而非本体系直接数据；
- 只有间接表征，没有区分性证据；
- 只有性能差异，没有产物/表面/中间体闭环；
- 句子使用了“证明、证实、主导、明确、决定、已发生”等强结论词。
### 2. 高风险说法：活性物种 / 高价态
以下说法默认不应直接写成正文事实：
- “本体系中 Co(IV)=O 已被证明存在。”
- “ClO2 是主导活性物种。”
- “本体系主要由高价钴驱动。”
- “已明确区分 ClO2 与 Co(IV)=O 的相对贡献。”
- “该体系属于非自由基主导机制。”
#### 推荐自动降级
- “结果提示 ClO2 与高价钴物种可能参与反应过程。”
- “现有证据与高价钴参与相符，但仍需更具区分性的验证。”
- “现阶段不能排除多类氧化物种并存贡献。”
- “关于主导物种与相对贡献，尚待进一步验证。”
### 3. 高风险说法：polymerization / coupling
以下说法默认不应写成“已观察到”：
- “本体系中污染物发生了聚合。”
- “去除主要归因于聚合沉积。”
- “中间体发生了偶联/寡聚化。”
- “催化剂表面形成了聚合膜/有机沉积层。”
- “本体系存在类似文献中的 polymerization pathway。”
#### 推荐自动降级
- “结合相关文献，不排除部分中间体存在偶联/聚合式去向。”
- “polymerization 目前仅可作为潜在竞争路径或启发性解释。”
- “现有结果不足以将 polymerization 作为已证实路径写入正文。”
### 4. 高风险说法：route tuning / pathway switching
以下说法默认应降级：
- “本体系实现了 selective oxidation / polymerization 的路径切换。”
- “氧化剂量决定了路径分配。”
- “本体系已建立 reaction pathway tuning。”
- “条件变化导致反应从深度氧化转为聚合。”
#### 推荐自动降级
- “文献提示氧化剂量可能影响反应去向。”
- “在本体系中，条件变化对路径分配的影响值得进一步考察。”
- “现有结果尚不足以宣称发生了明确的路径切换。”
### 5. 高风险说法：掺杂效应 / 电子结构归因
以下说法默认应降级：
- “Ce 掺杂改变了电子结构并促进高价钴生成。”
- “Ce3+/Ce4+ 与 Co2+/Co3+ 协同循环已证实。”
- “Ce 掺杂导致了反应路径改变。”
- “Ce 是活性提升的根本原因。”
#### 推荐自动降级
- “Ce 掺杂可能影响局部电子环境与反应行为。”
- “现有性能差异提示 Ce 掺杂具有调控作用，但具体机理仍待表征支持。”
- “Ce 与 Co 是否存在协同红氧循环，尚需进一步验证。”
### 6. 高风险说法：文献迁移
以下说法默认应降级：
- “某文献在 PMS 体系观察到 1O2，因此我体系也应如此。”
- “某文献中有 polymerization，因此我体系也有。”
- “文献中的高价金属机制可直接适用于本体系。”
- “因为底物相似，所以路径相同。”
#### 推荐自动降级
- “相关文献为本体系提供了有启发性的比较视角。”
- “该机制在相似体系中已有报道，但其对本体系的可迁移性仍需谨慎评估。”
- “文献可用于提出候选解释，不能替代本体系证据。”
### 7. 高风险词黑名单
以下词语一旦出现，应先检查是否需要整体降级：
- 证明
- 证实
- 明确
- 主导
- 决定
- 唯一
- 必然
- 已建立
- 已发生
- 已完成闭环
### 8. 安全替代表达
可优先改写为：
- 提示
- 与……相符
- 可能
- 不排除
- 值得注意
- 可作为启发
- 候选解释
- 尚待验证
- 仍需进一步证据支持
### 9. 写作自检问题
以后写到桥接句时，先问：
1. 这句话是我体系观察到的，还是文献里观察到的？
2. 我有直接证据，还是只有提示性证据？
3. 我是在写相关性，还是偷偷写成了因果性？
4. 如果审稿人追问证据路径，我能否给出本体系数据锚点？
只要其中任一问题答不上来，就自动降级。

## 当前结论压缩版
### 可进入写作的桥
- selective oxidation 不等于完全矿化；
- deeper oxidation 与 coupling/polymerization 可能构成竞争去向；
- 该旁支可作为 thesis discussion bridge 引入，但必须保持保守措辞。
### 只适合作讨论的桥
- Ce 掺杂如何调控高价钴；
- NaClO2 剂量是否能调路径；
- SMX 是否也有 coupling/oligomerization；
- 聚合是否带来氧化剂利用或副产物优势。
### 现在不该进正文的强结论
- “本体系已发生 polymerization。”
- “已严格证明 Co(IV)=O 为主导物种。”
- “Ce/Co 协同机理已明确。”
- “本体系已建立 route tuning。”
---
## 后续可补证据清单
若未来希望把“讨论桥”升级为“较强机制桥”，优先补：
- TOC 与母体去除同步性；
- LC-MS / MALDI / GPC 等产物链证据；
- 表面沉积的 FTIR / XPS / TEM-EDS；
- 更强区分度的高价钴/ClO2 证据；
- 氧化剂量-产物分布-表面沉积的联动矩阵。
