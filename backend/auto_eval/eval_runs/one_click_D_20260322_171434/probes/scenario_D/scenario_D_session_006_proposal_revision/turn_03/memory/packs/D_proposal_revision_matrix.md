# D proposal revision matrix
> 目的：梳理开题报告从准备脉路、范本约束、重构版 markdown、V3 PPT 到 final docx 的修订方向，不做逐字 diff，而强调 revision sense：哪些地方更锋利、哪些地方只是去掉含糊表述、哪些地方仍存在逻辑跳跃。
## 版本差异
### 1. `f1494f0d_【开题报告准备脉路】.md`
- **版本角色**：准备流程稿 / SOP 草图。
- **主要功能**：把开题准备拆成“文献意群搜索 → 每章单独组织 → canvas/PPT 汇总”的工作流。
- **主要在补什么**：补任务组织方式、时间线、文献管理与章节拆分思路。
- **主要删/淡化什么**：几乎不进入具体科学论证，不对 chlorite、Co3O4、活性物种等做正式主张。
- **revision sense**：这是“流程收束”，不是“科学收束”。
### 2. `b807daff_【开题报告】.md`
- **版本角色**：学院/组内范本约束。
- **主要功能**：给出开题必须覆盖的最小结构：背景与目的、相关进展、研究内容与技术路线、研究方法、时间安排、工作进展。
- **主要在补什么**：补交付容器的最低合规结构。
- **主要删/淡化什么**：删去自由发散的写法，不允许只凭个人叙事顺序展开。
- **revision sense**：把“怎么准备”转成“评审会看什么”。
### 3. `ae04a4a8_【开题报告】.md`
- **版本角色**：重构版 markdown / 学术写作骨架。
- **主要功能**：把范本重写成真正可写的绪论—方法谱系—主线工艺—设计策略—研究目的/内容/技术路线框架。
- **主要在补什么**：补“事实+空白”叙事、章节职责、图表位、篇幅比例与写作注意事项。
- **主要删/淡化什么**：删掉流程性语句、模板腔、教材式大综述表达。
- **revision sense**：从“结构合法”走向“叙事可用”，但仍偏通用骨架。
### 4. `76bb19d2_开题报告-颜雍颀-V3.pptx`
- **版本角色**：答辩叙事版 / 项目论证版。
- **主要功能**：第一次把课题压成完整主线：抗生素选择性氧化 → chlorite-based AOPs → Co3O4 调控 → 位点/物种/路径/应用闭环。
- **主要在补什么**：
  - 用“target motifs + accessibility”重写抗生素去除逻辑；
  - 明确 chlorite-AOPs 相比常规自由基 AOPs 的选择性、安全性与副产物叙事；
  - 提出三类 gap：主导活化位点不清、活性物种并存待判、复杂基质/应用闭环缺失；
  - 补入实验设计与前期结果：Ce 掺杂筛选、Ce:Co=0.5:5 最优、SMX 去除表现。
- **主要删/淡化什么**：压缩通用背景，减少教材式方法综述，把全部内容服务于答辩主线。
- **revision sense**：这是“最锋利也最容易越界”的一版。
### 5. `fde1237c_开题报告-颜雍颀(1).docx`
- **版本角色**：最终成文版 / 正式 proposal。
- **主要功能**：把 PPT 叙事展开为正式章节，形成研究背景、研究现状、研究内容、研究方法、工作进展与计划的书面版。
- **主要在补什么**：补正式文本结构、章节连续性、方法细节、阶段结果与时间安排的书面表达。
- **主要删/淡化什么**：删掉 PPT 口号化和单页强推式表达，把部分机制语言降级为“研究目标/待阐明问题”。
- **revision sense**：从强 pitch 回到可防守文本，增强的是边界控制，不只是篇幅增长。

## 增强项
### A. 真正“写得更锋利”的部分
#### 1. 评价标准被改写得更有辨识度
- 在 V3 PPT 中，抗生素去除不再只说“效率提升”，而是压成：
  - **selective oxidation depends on target motifs + accessibility**
- 这是从“做更强氧化”转向“做更定向氧化”的关键修订。
- 它使 chlorite 路线有了独立题理由，而不是普通 AOP 平移。
#### 2. 科学问题被压缩成可答辩的 gap
- V3 把空白收束为三条主线：
  - Co3O4 中主导活化位点不清；
  - ClO2 / Co(IV)=O / radicals 可能并存；
  - 复杂基质与应用闭环评价不足。
- 这比“现有研究仍有不足”更锋利，因为已经形成位点—物种—场景三层结构。
#### 3. final docx 的“克制”本身是一种增强
- 正式版没有把 Co(IV)=O 或 ClO2 直接写成已证实事实，而是改写成：
  - 需要阐明；
  - 需要揭示；
  - 需要建立。
- 这不是退让，而是把 proposal 语言从“推销型”修成“可答辩型”。
### B. 主要属于“去掉含糊表述”的部分
#### 1. 从泛 AOP 大综述收口到 chlorite-centered 叙事
- 这是必要的，但其中有相当一部分只是删去不相关方法与通用背景，令文本更干净。
- 它提升了聚焦度，但不自动等于证据更强。
#### 2. 从模板话转成学术骨架
- `ae04a4a8` 的价值很高，但很多提升体现在：
  - 不再教材式铺陈；
  - 用“事实+空白”收口；
  - 明确每一节为何存在。
- 这更多是叙事清理，不是科学闭环本身已经建立。
#### 3. final docx 的格式成熟度提升
- 正式版比 PPT 更完整、更像学位文本，但其中一部分改进来自：
  - 章节完整；
  - 句法规范；
  - 目标/内容/路线拆分清楚。
- 这些属于“成熟化”“去糊化”，不完全等于科学论证更硬。
### C. 版本间最关键的增强动作
#### 1. 准备脉路 → 范本 md
- 从“我如何准备”切到“评审要看哪些问题”。
- 增强的是容器意识。
#### 2. 范本 md → 重构版 md
- 从“格式正确”切到“叙事正确”。
- 增强的是论证意识。
#### 3. 重构版 md → V3 PPT
- 从“通用骨架”切到“这个课题为什么值得做”。
- 增强的是项目辨识度与主线锋利度。
#### 4. V3 PPT → final docx
- 从“答辩说服”切到“正式可防守”。
- 增强的是边界感和学术语气，而非激进程度。

## 仍需修补
### 1. 文献先例 → 你的体系：桥接仍不够
- 目前文本中容易从“文献中高价金属或 ClO2 可选择性攻击电子富集位点”直接跳到“你的 Co3O4/chlorite 体系也按此主导运行”。
- 需要补：
  - 该机制在本体系中的证据等级；
  - 适用边界；
  - 与其他可能路径的区分方式。
### 2. 位点调控 → 主导活化位点：仍有偷跑风险
- PPT 已正确提出“Td-Co2+ / Oh-Co3+ 作用仍不清楚”，但局部表述仍会给人“Co3+ 生成 Co(IV)=O 并主导反应”已成立的印象。
- 需要补：
  - 位点判别逻辑；
  - 掺杂后电子结构变化与活性物种之间的中间桥梁；
  - 结构—性能—机制的分层结论。
### 3. 探针设计 → 贡献分摊：中间缺证据等级说明
- V3 的机制页已经写到 “Contribution of ClO2 vs Co(IV)=O”，这在表述上略显超前。
- 需要补：
  - PMSO、DPD 等探针的干扰排查；
  - 空白与对照；
  - 不同活性物种之间的正交区分；
  - 只能支持“存在/参与/相对贡献趋势”还是已能支持“定量分摊”。
### 4. 单一模型底物 → 结构多样抗生素：外推仍偏快
- 当前期结果最扎实的是 SMX 条件下的 Ce 掺杂筛选与性能优化。
- 但标题和部分叙事已进入“structurally diverse antibiotics”的一般化命题。
- 需要补：
  - 代表性底物矩阵；
  - 官能团/位点层面的规律归纳；
  - 为什么可从 SMX 外推到更广抗生素谱系。
### 5. 性能筛选 → 应用闭环：还要防止愿景提前落地
- 稳定性、scenario tests、application translation 在 V3 中已经列入计划，这是合理的。
- 但当前更像研究计划，而不是已有系统优势。
- 需要补：
  - 复杂基质评价；
  - 副产物与安全性边界；
  - 连续流/固定床等应用语言与现阶段证据的匹配程度。
### 6. Ce 掺杂进入主线后的“为什么”还不够强
- 目前有“Ce-Co3O4 最优”的结果锚点，但“为什么是 Ce，而不是 Al/Mg 等其他掺杂元素”的论证仍可加强。
- 需要补：
  - Ce 对 Co 价态分布、氧配位环境、chlorite 相互作用或活性物种生成的特异作用；
  - 与其他掺杂的对比逻辑，而不只是结果排序。

## 可直接复用的总判断
这套开题的修订并不是单纯“越写越长”，而是经历了：
- **流程收束**：先把工作组织起来；
- **容器校准**：先满足开题的必答结构；
- **叙事收口**：从模板腔转为事实+空白；
- **主线锋利化**：提出 selective oxidation / chlorite / Co3O4 的独特论证；
- **边界克制化**：把过强机制断言改写为可防守的研究目标。
最成功的增强，不是增加段落，而是把 proposal 从泛综述改成了“有主线、有边界、有待证问题”的项目论证。最需要继续修补的，不是文采，而是把“文献先例—你的体系—你的证据”三层桥接补齐。
