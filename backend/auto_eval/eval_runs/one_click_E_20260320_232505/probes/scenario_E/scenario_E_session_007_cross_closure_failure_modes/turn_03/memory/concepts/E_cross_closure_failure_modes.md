## 二、误迁移模式
> 这里的“误迁移”指：把低确定性、低层级、低完成度的信息，跨层搬运成高确定性陈述。

## 三、防呆规则
### A. 句子级防呆
1. **每个机制句都要带证据锚点**  
   最少写清：`样品 + 体系 + 方法 + 当前状态（文献启发/计划中/已观察/已验证）`。
2. **只要源文本里有不确定词，输出就不能升级成确定词**  
  典型不确定词：`可能 / 也许 / 如果 / 看情况 / 暂时 / 先不急 / 待验证`。  
   若源文本含这些词，输出不得改成：`证明 / 揭示 / 证实 / 已建立 / 已完成`。
3. **计划、todo、周安排不得改写成完成事实**  
   凡是出现 `todo / 优先做 / 明天 / 周二 / 周三 / 准备 / 先做` 的段落，只能输出为计划、待执行或建议，不得写成结果。
4. **图源不等于图证**  
   凡是含 `图源 / 主结构参考 / 参考文献` 的内容，只能说“参考写作结构/参考图式”，不能说“本研究结果显示”。
5. **方法条件不等于本实验 run condition**  
   文献 SI 中的 EPR / CV / PMSO / DPD 条件，除非在自己的 run log 或结果记录中再次出现，否则只能表述为“参考条件”。
### B. 文件级防呆
6. **先判源层级，再决定语气等级**  
   推荐给每段源内容打标签：
   - `reference`：文献摘录/外部启发
   - `plan`：todo/实验计划/待办
   - `draft`：写作大纲/图版草稿
   - `result`：本实验观察
   - `memory`：已沉淀的稳定判断
7. **仅凭文件名不得判定确定性**  
   `PACK`、`主线`、`工作文档`、`AOPs` 等标签都不自动代表“稳定结论文件”；必须看正文体裁。
8. **assets/uploads 不直接等于稳定知识**  
  只有当内容被明确整理并沉淀到 `memory/` 后，才能用“当前稳定共识/长期判断/已确认事实”等语气。
9. **跨文件存在版本冲突时，先报冲突，再给当前有效版本**  
   禁止静默挑选最顺手的一版。  
   最常见冲突例子：`Ce 让 Co 静态升价` vs `不再说静态升价`。
10. **写作文档中的章节树、图号、构图方案不得直接升格为证据链**  
   章节规划只能证明“想怎么写”，不能证明“已经做到什么”。
### C. 闭环级防呆
11. **先冻结 claim，再冻结实验矩阵，再冻结写作骨架**  
    当前高风险顺序正相反：claim 未冻结，实验矩阵未冻结，写作骨架先冻结。
12. **机制证明体系与性能体系分开记账**  
    blank/probe 体系用于机制；SMX/PhOH 体系用于性能或应用。  
    禁止同一组数据同时承担“主机制证据”和“污染物性能主证”两种职责。
13. **建立 claim registry**  
    每个主 claim 只保留 1 个“当前有效版本”，其余版本标记为：
    - `已废弃叙事`
    - `候选解释`
    - `待验证`
14. **建立 figure-claim anchor 表**  
    每张图必须回答：
    - 它只证明什么？
    - 它不能证明什么？
    - 它依赖哪组样品、哪种体系、哪类对照？
15. **建立 evidence status 标签**  
    建议统一 4 级：
    - `L0 文献启发`
    - `L1 计划中`
    - `L2 已观察`
    - `L3 已验证`
    任一句话的确定性，不得高于其证据等级。

## 四、可直接用于 hallucination 审计的高危信号
1. 源文本有 `可能/也许/如果/待验证`，输出写成 `已证明/揭示/说明`。
2. 源文本有 `todo/优先做/周二测/准备做`，输出写成 `已经完成/已经观察到`。
3. 输出出现 `4f-2p-3d / O-trapping / Bader / d-band center / CPET` 等文献术语，但无本体系证据锚点。
4. 输出把 `图源/主结构参考` 改写成 `结果显示/本研究发现`。
5. 输出直接复用了文献 SI 的精确实验条件，却未标注“参考条件”。
6. 同一 claim 在多文件冲突，输出未报冲突而直接选一版。
7. 仅凭 `PACK/工作文档/主线` 等文件名，输出高确定性结论。
8. 把 `assets/uploads` 中的混层笔记直接说成 `当前稳定共识`。

## 五、当前最关键的一句话诊断
当前最核心的跨闭环失效模式不是“没做实验”，而是：
> **同一主 claim 在文献启发、实验计划、写作草稿、source 笔记中处于不同版本，模型很容易把低确定性版本静默升级成高确定性结论。**
可进一步概括为：
> **claim 没冻结 → 实验矩阵没冻结 → 写作骨架先冻结 → 误迁移与断链同时发生。**
