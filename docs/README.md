# Docs 目录说明

当前 `docs/` 已按主题整理，优先按下面的目录查找：

- `架构/`: 架构总览、PRD/TAD、架构图、阶段性架构 HTML
- `启动协议/`: BOOTSTRAP 协议设计与演化文档
- `阶段/`: Phase 1 到 Phase 6 的计划、日志、索引、阶段架构
- `分析/`: 安全分析、trace 改进、sanitization、问题修复记录
- `报告/`: 集成报告、测试结果说明
- `指南/`: 启动说明、review/playbook、仓库说明
- `仓库导出/`: repomix 合并导出文件
- `脚本/`: 放在 docs 下的演示脚本、测试脚本、安装脚本
- `规范/`: 配对调试规范、可追溯闭环 demo 规范
- `笔记/`: 临时笔记、问题记录
- `总结/`: 项目总结、面试/表达材料
- `zly交接/`: 迁移设计和专项分析材料
- `专项规范/`: 现有专项 spec 文档

如果后续新增文档，建议优先放进对应分类目录，不再直接散落到 `docs/` 根目录。
