4. 核心模块职责

App.tsx
主布局组件。顶部控制栏（workspace/session 选择器）+ 三栏工作台。装配 10+ useQuery 和 4 useMutation，根据 bootstrap_status 条件渲染 BootstrapGate 或 ChatPanel。
apiClient (client.ts)
workspace-aware API 客户端工厂。所有请求自动注入 X-Workspace-Id header。封装 probe/workspaces/sessions/files/assets/chat 全部后端接口。
streamSse (sse.ts)
独立 SSE 解析模块。从 ReadableStream 逐行解析 event/data，分发 token/tool_start/tool_end/new_response/done/error 事件。
store.ts (Zustand)
UI 状态管理。apiBase/connection/currentWorkspaceId/currentSessionId/preview/tracePanelOpen。persist 中间件持久化关键字段到 localStorage。resetWorkspaceScope() 防止跨 workspace 状态串联。
BootstrapGate.tsx
Bootstrap 拦截组件。pending/failed/running 状态下阻止进入普通 chat，显示对应文案和操作按钮（开始初始化/重试/刷新状态）。
ChatPanel.tsx
聊天面板。历史消息渲染 + 实时流式消息（liveTurn 状态机）。SSE token 追加、tool 审计记录、附件上传队列、route 参数 hash 解析。
FileTreePanel.tsx
文件树面板（左右栏复用）。递归 TreeNodeView 渲染目录/文件，分 section 展示（Control Plane/Identity/Timeline/Skills/Concepts/Tasks/Packs）。点击文件触发预览。
TracePanel.tsx
Trace 审计浮层。固定定位，展示 trace envelope 中的工具调用记录，按时间倒序排列，显示工具名/状态/参数/结果。
types/api.ts
前端类型定义层。18 个 TypeScript 类型/接口，与后端 Pydantic 模型一一对应。StreamEvent 联合类型覆盖全部 SSE 事件。

6. 关键决策记录

决策 1：React + Vite + TypeScript，不用 Next.js
项目是纯 SPA 对接后端 API，无 SSR 需求。Vite 提供最快的 HMR 和构建速度，React 18 生态成熟。
决策 2：Zustand 管理 UI 状态，TanStack Query 管理服务端状态
workspace/session/history/tree/manifest 等服务端数据由 React Query 管理（自动缓存/失效/重试）。apiBase/connection/preview 等纯 UI 状态由 Zustand 管理。职责清晰，避免 Context 嵌套地狱。
决策 3：apiClient 工厂模式，不用全局单例
createApiClient() 接收 baseUrl 和 getWorkspaceId 回调，每次调用时动态读取当前 workspace。避免 store 变更后 client 引用过期。
决策 4：SSE 解析独立为 sse.ts 模块
从 ChatPanel 中抽离 SSE 解析逻辑，使其可独立测试。后续扩展 bootstrap stream / retrieval stream 时只需复用同一解析器。
决策 5：全局 CSS 而非 CSS Modules
Phase 6 优先保证功能完整和测试覆盖，CSS 模块化留给后续迭代。当前 540 行全局 CSS 在组件数量有限时可控。⚠️ 已标记为技术债。
决策 6：Vitest 排除 Playwright 测试目录
tests/ 目录下的 Playwright spec 使用 @playwright/test 运行时，与 vitest 不兼容。通过 test.exclude 隔离，两套测试各自独立执行。
