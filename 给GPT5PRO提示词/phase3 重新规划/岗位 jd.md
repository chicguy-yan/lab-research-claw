# AI产品经理（深圳）

## 岗位职责

1. **需求与场景拆解**：面向科研用户（研究生/PI/企业研发）梳理核心流程：检索—阅读—归纳—实验/计算—复现—沉淀，将“科研痛点”转为可执行的产品需求与优先级（PRD/用户故事/验收标准）。

2. **AI 能力产品化**：协助设计并迭代 RAG/多轮对话/结构化抽取/工具调用（Tool Use）/Agent 任务编排等能力的产品形态。输出 Prompt/模板/约束、评测用例集、失败案例归因（幻觉、引用缺失、证据不足、工具失败）。

3. **数据与评测体系**：参与构建“金标/精标”评测数据：论文/专利/报告的结构化字段、图表公式、多模态证据链，设计指标并推动落地：命中率、引用/证据完备度、答案一致性、可复现性、任务完成率、响应时延等。

4. **竞品与行业研究**：跟踪并对标学术搜索/科研助手：检索效果、引用规范、工作流闭环、权限与合规、定价与商业化打法，形成可复用的竞品对比材料与机会点建议。

5. **版本推进与跨团队协作**：跟进研发/算法/数据/运营进度，组织评审与验收，输出 Release Note、产品手册关键段落、演示脚本（Demo Script）。

## 职位要求

1. 本科/硕士在读，理工科优先（化学/材料/生物/医药/计算机/信息等）。
2. 强结构化能力：能把复杂问题拆成“输入→处理→输出→验收”的规格。
3. 对 AI 工程/产品理解到位：至少了解 RAG、向量检索、评测、Prompt、工具调用/Agent 的基本逻辑。
4. 熟练使用文档工具（飞书文档等）与原型工具（Figma）。
5. 具备基础数据分析能力（Excel/SQL/简单 Python 加分）。
6. 沟通与推进能力强：能推动问题闭环，而不是只“记录会议纪要”。

## 加分项

1. 做过科研类产品/学术搜索/知识库/数据平台/Agent 项目。
2. 有论文/专利/实验数据处理经验，理解科研写作与引用规范。
3. 熟悉信息检索（BM25/向量检索/混合检索/重排）、实体抽取、结构化解析。
4. 有评测集构建经验：用例设计、抽检规则、错误类型体系、标注规范。
5. 有 B 端产品经历（权限、审计、合规、SLA、成本与性能）。
