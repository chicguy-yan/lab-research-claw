		- 一般情况下淬灭剂/探针就是反应体系
	- 显色反应
		- 一般情况下反应体系是纯水

PMSO探针淬灭剂用什么？
- 常规

| 体系情况                   | 合适的淬灭剂          | 理由                          |
| ---------------------- | --------------- | --------------------------- |
| 【氧化剂】PMS / PDS Co 活化体系 | **Na₂S₂O₃（首选）** | 迅速还原所有过氧化物、停止生成 Co(IV)      |
| 【氧化剂】氯系（ClO₂⁻/ClO₂）体系  | **Na₂S₂O₃（首选）** | 迅速还原 ClO₂ / ClO₃⁻，阻断再生成 ROS |
| 【非自由基】O₂·⁻ / ¹O₂ 主导体系  | NaN₃ 或过量甲醇（副用）  | 主要阻断 ROS 链反应，不针对金属中间体       |
| 强自由基（·OH、SO₄·⁻）体系      | MeOH / TBA      | 捕获自由基，阻断后续反应                |

- 在高价Co当中淬灭剂淬灭的东西是【氧化剂】，防止它继续活化生成四价Co
它自己本身并不能马上淬灭Co
