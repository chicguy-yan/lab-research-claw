2026-02 ~ 至今 ResearchLoop-OpenClaw｜面向生化环材科研的 AI-native 工作流系统 独立开发者
需求洞察：
· 在真实的生化环材科研中，文献、原始数据、汇报材料和论文常分散在不同仪器、记录本或文件夹中；在文献调研、实验计算与汇
报写作等跨环节推进时，研究者需要反复翻找和重建上下文，严重拖慢科研效率。
· 基于这一真实场景痛点，本产品结合 OpenClaw 记忆系统设计与本地文件管理，提出“用 AI 串联并沉淀科研任务流”：系统可
双向关联实验、文献与阶段成果，将零散研究过程转化为可持续推进的科研闭环。
功能设计：
· 参考 OpenClaw 的记忆系统设计：在 Layer1 / Layer2 中沿用 OpenClaw 的 File-first 思路，以本地markdown文件持续沉淀研
究背景、实验记录与阶段上下文，为长期科研任务提供可积累的记忆基础。
· 在 Layer3 中抽象科研工作的最小任务单元： 设计 Concept（研究主题）、Task（实验任务）、Pack（阶段成果）三类科研工作
资产，分别组织文献调研、实验流程与阶段汇报，使研究知识、实验动作与阶段产出进入统一 memory 体系。
· 用 AI 将研究材料自动组织为持续推进的科研任务流：研究者只需持续上传文献、实验数据或研究笔记，系统即可关联历史文献、
实验记录与阶段成果，生成实验建议、证据链摘要或汇报结构，并同步更新对应 Task 或 Pack，使“读文献—做实验—写汇
报”形成持续推进的科研闭环。
评测体系：
· 180 天科研生命周期 JSON benchmark： 基于真实实验室研究记录与长期 memory，构建 300 轮科研对话与任务推进数据，
用于模拟文献调研、实验设计与阶段总结的连续研究过程，并在开发测试中实现 90%+ 场景上下文命中率。
· 科研闭环场景测试集： 设计“主题文献-研究假设提出”、“实验原理-操作流程-实验结果”、“阶段性汇报与论文写作”三类典
型科研任务场景，验证系统在研究流程各阶段的任务组织与信息关联能力。
· AI-native 开发协作流程：采用 CC 负责架构设计与复杂度收敛、Codex 负责代码审查与 debug 的协作模式，累计完成 5 个开发
阶段 / 34 个核心模块迭代，并通过前端真实试用完成 40+ 次端到端测试回合。
